7. Свои 3D-модели и Blueprint-объекты

Импортируем FBX из Blender, разбираем текстуры и материалы, чиним Collision и делаем интерактивный телевизор (вкл/выкл, звук, светящийся экран). После — второй пример на выбор.

Что мы сделаем

Возьмём простую модель телевизора (корпус + экран отдельно), импортируем в Plugins/ВашМод/Content/Meshes/, создадим материал с выключающимся экраном и Blueprint BP_TV: E включает (звук шипения + Emissive + Point Light), повторное E выключает.

⚠️
Важно: форматы для UE 4.20.3

Модели — FBX 2014–2018 (бинарный), триангулированные. Не используйте glTF/USD — 4.20 их не знает. Текстуры — TGA/PNG 1024–2048, Normal в формате DirectX (не OpenGL, иначе швы). Скелетные меши — только FBX с bones (см. замену соседа).

Подготовка модели: масштаб, Pivot, UV

  • Масштаб: 1 unit Blender = 1 см UE. Телевизор 60×40×40 см. В Blender: Apply Scale (Ctrl+A → Scale), иначе в UE Scale 0.01 и физика сходит с ума. Проверка: куб 100 см должен быть по пояс персонажу (рост ~180).
  • Pivot: origin в центре основания (низ телевизора). Тогда он встанет на стол ровно, а не «утонет». В Blender: Origin to Bottom.
  • UV: у каждого меша должна быть развёртка 0–1 без наложений. Вторая UV (Lightmap) для Static — UE сгенерирует сам (Generate Lightmap UVs при импорте), но первая обязана быть чистой, иначе «пятна» после Build.
  • Материалы: в Blender 2 материала: M_Body (пластик) и M_Screen (экран). Экран — отдельным мешем/полигоном, иначе не переключим Emissive!
  • Имена: только латиница: SM_TV_Body, T_TV_Screen_BC. Русские буквы = розовый материал при упаковке.

Импорт FBX в Mod Kit

1

Экспорт из Blender

File → Export → FBX: Scale 1.0, Apply Unit, Forward -Z Forward / Up Y Up, Selected Objects only, Mesh + Materials. Версия FBX 7.4 (2014+). Сохраните рядом текстуры PNG.

2

Import в Content Browser

В папке плагина Content/Meshes → Import → выберите FBX. Галочки: Import Materials=false (создадим сами!), Import Textures=false (импортируем отдельно!), Auto Generate Collision=true, Generate Lightmap UVs=true. Почему без материалов? Авто-материалы из Blender дают розовые слоты — лучше назначить свои.

3

Текстуры отдельно

Import PNG/TGA в Content/Textures. В каждой: Compression: BaseColor → Default (sRGB on), Normal → Normalmap (sRGB off!), Roughness/Metallic → Masks (sRGB off!). Ошибка sRGB у Normal = «пупырчатая» модель.

Свой Material с нуля

★

M_TV_Screen: экран, что гаснет

Add New → Material → M_TV_Screen. Перетащите текстуру экрана в граф → соедините в Base Color. Добавьте Scalar Parameter ScreenOn (1.0) → Multiply на Emissive Color → в Emissive. Roughness 0.15 константой. Сохраните. Теперь Blueprint будет крутить ScreenOn 1↔0 — экран гаснет без смены материала! Для корпуса — M_TV_Body: BaseColor + Roughness 0.6, Metallic 0.0.

Розовый материал? Значит слот пустой или текстура не найдена (переместили .uasset проводником). Назначьте материал в Static Mesh → Materials → Element 0/1 → Save.

Collision: почему проходят сквозь

  • Simple — коробка вокруг (быстро). Для ТВ, стен, мебели. Создать: открыть меш → Collision → Add Box Simplified → Save.
  • Complex — точно по треугольникам (медленно). Только для статуй, где важна каждая выемка. В Details меша: Collision Complexity → Use Complex as Simple (осторожно с FPS!).
  • Свой UCX_ — в Blender делаете бокс UCX_TV_01, экспортируете вместе. Для точных проёмов.
  • Диагностика: в Viewport Show → Collision (красные каркасы). Нет каркаса = NoCollision = провал. В Details меша Collision Preset должен быть BlockAll.

Практика: телевизор + ещё пример

1

BP_TV: компоненты

Blueprint Actor → BP_TV: SM_TV_Body (Static, BlockAll) + SM_TV_Screen (Static, NoCollision — чтобы не мешал) + Point Light (выкл, Intensity 800, Radius 400, тёплый) + Audio (шипение) + Box Trigger. Переменные: IsOn (bool=false), MID_Screen (Material Instance Dynamic).

2

Логика вкл/выкл

BeginPlay: Create Dynamic Material Instance (M_TV_Screen) → Set на экран → сохранить в MID_Screen → Set ScreenOn 0. На E (FlipFlop): A (вкл): Set IsOn=true → Set Scalar ScreenOn 1.0 → Light Visible true → Play Sound → Widget «Телевизор включён». B (выкл): наоборот. Dynamic Instance обязателен — иначе крутите общий материал и гаснут все ТВ на карте!

BeginPlay → Create Dynamic Material → Set на экран
↓
E → FlipFlop → A: ScreenOn 1.0 + Light on + звук | B: 0.0 + off

Второй пример — лампа-ловушка: тот же BP, но вместо экрана — Spot Light + звук гудения. Подключите к генератору из продвинутых: пока нет питания — E даёт «Нет электричества». Один BP — два предмета, разница только в свете и тексте.

💡
Совет: как улучшить

Добавьте переключение каналов (3 Emissive-текстуры по кругу), шум при «нет сигнала», выключение при выходе из комнаты (EndOverlap → off — экономия FPS).

Проверка + ошибки

  • Модель встала в правильном масштабе (не с дом / не с ноготь).
  • Стоит на столе ровно, не тонет, Collision BlockAll виден.
  • Материал не розовый, экран гаснет/зажигается, свет синхронен.
  • Второй ТВ на карте управляется независимо (Dynamic!).
Модель гигантская / крошечная

Blender Unit не см или не Apply Scale. Переэкспортируйте со Scale 1.0. Временно — Scale в Details, но физика будет врать.

Розовый / шахматный материал

Нет текстуры в слоте или sRGB перепутан. Назначьте материал заново, проверьте пути (не двигали проводником?).

Прохожу сквозь модель

NoCollision. Добавьте Box Simplified Collision + BlockAll + Save. Проверьте Show → Collision.

Гаснут все телевизоры сразу

Крутите общий Material, а не Dynamic Instance. Создайте MID на BeginPlay для каждого ТВ.
