10. Свои объекты в оригинальных актах — спавн по F

Делаем мод, который в ОРИГИНАЛЬНЫХ картах актов по нажатию F добавляет ваш объект: Action Mapping, спавнер-Blueprint, точка перед игроком, безопасность Collision, упаковка в .pak. Честно про ограничения — по материалам ModDB, Steam/Reddit-моддеров и доков UE 4.20.

★★ СреднеНОВОЕF = спавн

Как это работает на самом деле (без мифов)

Моды в Mod Kit — это UE-плагины (Edit → Plugins → New Plugin, упаковка кнопкой Package в .pak для Workshop — гайд ModDB «Hello Neighbor Modding Guide»). Официального API «вживить любой объект в нетронутые акты во время игры, не трогая карту» в ките нет. Надёжный путь, проверенный сообществом (гайд по установщикам DrHello, моддеры Reddit): скопировать карту акта в свой плагин → добавить туда логику спавнера → упаковать. Игроки играют в ВАШУ копию акта (например Act1_MyMod), где F работает. Обещать «нажал F в чистом стим-акте — появился стул без изменения карты» было бы неправдой — честно пишите: мод = модded-копия акта + контент плагина.

⚠️
Важно: оригиналы не трогаем

Только копия: правый клик по карте акта → Duplicate/Migrate в /Mods/ВашМод/Content/Maps/. Оригиналы целы для обновлений и чужих модов.

Копия акта, не оригинал

1

Находим акт и копируем

В Content Browser поиском ищем карту акта (имена зависят от сборки: Act1 / StartupMap / MainMap — ищите, не гадайте). Правый клик → Duplicate в папку Maps вашего плагина → имя Act1_FSpawn (латиница, без пробелов). Открываем СВОЮ копию. Проверяем Player Start и Lightmass Importance Volume, жмём Alt+P — бегаем.

2

Объект для спавна

Любой BP_AmmoBox / SM_Crate или ваша своя модель: нужен Simple Collision (иначе провалится) и Mobility Movable при физике. Scale 1.0, Pivot снизу. Сначала поставьте копию вручную — если ручная глючит, заспавненные тоже будут.

Кнопка F: Action Mapping (старый инпут 4.20!)

Edit → Project Settings → Engine → Input → Action Mappings → + → имя SpawnObject → клавиша F. Это СТАРАЯ система ввода — в ките (4.20.3) нет Enhanced Input, туториалы UE5 с IA_ не подойдут. В Character или Level Blueprint: правый клик → событие InputAction SpawnObject появится само после маппинга. Не появилось — закройте/откройте Project Settings (фирменный глюк 4.20).

Спавнер: F → объект перед игроком

3

Граф (в PlayerCharacter или BP_Spawner на копии акта)

InputAction SpawnObject (F) → Branch [CanSpawn? кулдаун прошёл] → позиция игрока + Forward × 200 см + Z +50 → Make Transform → Spawn Actor From Class (ваш BP, Collision Handling = Adjust If Possible But Always Spawn) → звук + счётчик → Do Once + Retriggerable Delay 0.5с. Спавн впереди — иначе объект внутри игрока и физика взрывается. Collision Handling обязателен, иначе спавн в стене тихо не сработает.

InputAction SpawnObject (F)
↓
Позиция + Forward×200 + Z50 → Make Transform → SpawnActor (Adjust Always Spawn)
↓
DoOnce + кулдаун 0.5с → звук + счётчик
Forward × 200 — точка перед глазами, а не внутри черепа. Spawn Actor From Class — нужен Class (ваш BP) + Transform; возврат = созданный экземпляр (храните в Array, лимит 20, старых удаляйте). Do Once + Delay — анти-спам: держать F на 60 FPS без кулдауна = 3600 ящиков. Play Sound at Location — подтверждение.
💡
Совет: улучшения

Цикл 3 объектов по F (Array + index++), спавн за предмет (Branch HasItem → Remove), спавн только в точку прицела (Line Trace → Hit Location).

Упаковка и игра

Edit → Plugins → ваш мод → Package → .pak/zip → Upload в Workshop (Steam запущен, игра куплена) или файл на ModDB. Игроки: подписаться/скопировать .pak → играть в ВАШУ копию акта из меню мода, жать F — объект появляется. Тестируйте упакованный билд, а не только PIE: кукер выкидывает неиспользуемые ассеты, поэтому сошлитесь на BP с карты (поставленный спавнер) или добавьте в Project Settings → Packaging → List of maps to include. Источники: ModDB Modding Guide (плагин/упаковка/игра), туто DrHello, доки UE 4.20 Input + SpawnActor, доки Epic по меню/UMG.

F не работает / спавн внутри меня / краш / нет в пакете?

Нет события: имя маппинга не совпадает или старый инпут — пересоздайте + перезапустите редактор. Внутри меня: +200 вперёд + Z50 + Adjust-Always-Spawn. Краш: пустой Class или бесконечный спавн на Tick (только событие Pressed + кулдаун). Нет в пакете: жёсткая ссылка с карты + список карт в упаковке.
