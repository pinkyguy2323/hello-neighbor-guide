1. Объект невидимый

Причина: Hidden in Game, видимость выкл в Outliner (глазик), материал прозрачный (Opacity 0), меш задом наперёд (Normals внутрь), или актор под землёй.

Диагностика: Outliner → двойной клик по имени (камера прилетит). Если прилетела под землю — Location Z. Если на месте, но пусто — проверьте Hidden/Visibility + откройте меш (видно ли в редакторе меша?).

Фикс: снять Hidden, Opacity вернуть, Flip Normals в Blender при перевёрнутости, поднять Z. Профилактика: не ставьте Scale 0 даже «временно» — забудете.

2. Игрок проходит через объект

Причина: Collision Preset NoCollision / Overlap вместо BlockAll, нет Simple Collision у импортированной модели.

Диагностика: Viewport Show → Collision: нет красного каркаса = нет Collision. Details → Collision Enabled должно быть Query and Physics.

Фикс: BlockAll + Add Box Simplified Collision + Save. Профилактика: проверяйте Collision сразу после импорта (см. урок 7).

3. Blueprint не запускается / Event BeginPlay не работает

Причина: актор не стоит на уровне (лежит в папке), BeginPlay в Construction Script, Level Blueprint переопределил GameMode, Simulation выкл.

Диагностика: повесьте Print String «Я жив!» в самое начало BeginPlay. Молчит = актора нет на сцене или не тот уровень открыт. Говорит = дальше по белой стрелке обрыв.

Фикс: перетащить Blueprint на уровень, перенести логику из Construction в BeginPlay, Compile + Save. Подробнее — основы Blueprint.

4. Trigger не реагирует

Причина: Generate Overlap Events=false, Collision Block вместо Overlap, нет Cast к игроку (срабатывает, но Branch режет), триггер слишком мал/внутри стены.

Диагностика: на BeginOverlap повесьте Print «Кто-то вошёл» без Cast. Печатает = проблема в Cast/фильтре. Молчит = Collision/размер/позиция.

Фикс: OverlapAllDynamic + Generate Overlap + вынуть из стены + Cast To Player + IsValid. Размер Box минимум 150 см.

5. Дверь вращается вокруг неправильной точки

Причина: Pivot в центре полотна вместо петли. Классика всех новичков.

Фикс: Scene Component DoorPivot на краю проёма → полотно вложить → вращать Pivot через SetRelativeRotation. См. головоломки.

6. Свет слишком яркий / после Build всё стало тёмным

Ярко: два Directional друг на друге, Intensity 10 вместо 3, Exposure 2.0. Удалите дубликат в Outliner, верните 3–4 / 1.0.

Темно после Build: нет Lightmass Importance Volume, свет Static без запекания, Intensity 0. Добавьте Volume вокруг дома → Build Preview → проверьте. Временно переключите всё на Movable чтобы убедиться, что дело в запекании.

7. Модель импортировалась слишком маленькой / большой

Причина: Blender Unit не сантиметры, не Apply Scale, FBX Scale 100/0.01.

Фикс: переэкспорт Scale 1.0 + Apply. Временно — Scale в Details, но физика будет врать. Рост персонажа 180 см — линейка.

8. Материал розовый или отсутствует

Причина: пустой слот, текстура удалена/перемещена проводником, sRGB перепутан, русские буквы в пути.

Фикс: назначить материал в Element 0/1, реимпорт текстур, только латиница в именах, Normal — sRGB off. См. материалы.

9. Blueprint выдаёт Accessed None / Cast Failed

Accessed None: читаете пустую ссылку (игрок удалён, дверь не назначена пипеткой). Фикс: IsValid перед каждым чужим Get + дефолтные значения.

Cast Failed: Cast к игроку, а вошёл стул. Фикс: обработайте пин Failed (ничего не делать) или проверяйте класс заранее. Это не ошибка движка — это ваш фильтр сработал, радуйтесь!

10. Infinite Loop (зацикливание)

Причина: Tick → Spawn → Overlap → снова Tick без DoOnce; WhileLoop без выхода; два Dispatcher звонят друг другу.

Диагностика: редактор завис + окно Infinite Loop с указанием ноды. Откройте — там стрелка на виновника.

Фикс: DoOnce + Cooldown Delay, счётчик итераций в цикле (Loop < 1000 + Break), разорвать кольцо через Interface. Никогда не вешайте Spawn на Tick без задержки!

11. AI не двигается / сосед стоит в T-Pose

Не двигается: нет NavMesh Bounds Volume (Place Actors → Volumes → растянуть + Build Paths), AI Controller не назначен, Capsule в стене.

T-Pose: нет Anim Blueprint или чужой Skeleton. Верните родной Anim Class, проверьте Skeleton (см. замену соседа), зоны BP_Area* на месте.

12. Игра сильно тормозит

Причины по весу: 1) 50 Movable-теней + 4K-текстуры; 2) Tick без фильтров; 3) Complex Collision везде; 4) гигантский Landscape 505+ без LOD; 5) 20 Print String каждый кадр.

Фикс за 10 минут: свет Static где можно + Build, текстуры 2048→1024, LOD Auto, Tick → Timer 0.2с, удалить Print, Stat FPS/Stat Unit для замера. Цель — 60 FPS на средней карте.

Чек-лист перед упаковкой мода

  • Карта в папке плагина, имя латиницей, Ctrl+S, Build Lighting без красных ошибок.
  • Player Start над землёй, зоны Area + GeneralSwitch (если дом соседа) на месте.
  • Все Blueprint Compile без ошибок, нет Accessed None в логе Play.
  • Убраны Print-отладки, виджет один, звук везде есть.
  • Тест с нуля: ключ → дверь → лом → доски → карта → слив → финал проходится.
  • Package → тест .pak на чистой копии + подпись в Workshop с иконкой.
