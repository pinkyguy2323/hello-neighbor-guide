2. Объекты и строительство собственного дома

Учимся искать и ставить Static Mesh, разбираем Collision и материалы, строим двухэтажный дом пошагово: пол → стены → окна → лестница → крыша → свет → мебель. Два подхода: из готовых ассетов Mod Kit и полностью свой дом.

Что мы сделаем

Построим дом 8×8 м, 2 этажа, с окнами, дверным проёмом, лестницей, крышей и светом в каждой комнате. Поймём, почему стены должны стыковаться по сетке 100 см, а Collision — это не сама стена, а невидимая оболочка вокруг неё.

Static Mesh — неподвижная 3D-модель: стена, пол, стул. Collision — невидимая форма, которая решает, проходите вы сквозь объект или упираетесь. Pivot — точка, вокруг которой объект вращается и к которой «прилипает» при перетаскивании. Snap — привязка к сетке, чтобы стены вставали ровно.

Как искать и ставить объекты

1

Ищем Static Mesh

Content Browser → строка поиска → вбейте SM_Wall, SM_Floor, SM_Door, SM_Stair, wall, floor. В Mod Kit ищите папки игры (HelloNeighbor / Meshes / House — точное имя зависит от сборки, пользуйтесь поиском). Фильтр Static Mesh уберёт лишнее. Понравилось — перетащите на Viewport, а не двойным кликом (двойной клик откроет редактор меша).

2

Transform: двигаем точно

Выберите объект → Details → Transform: Location (X/Y/Z), Rotation, Scale. Для ровного дома ставьте кратные 100: стена длиной 400 см → следующая на +400 по X. В Viewport: W — стрелки перемещения, E — круги вращения, R — кубики масштаба. Угол поворота стен — строго 0/90/180, иначе щели.

3

Копирование, дублирование, группировка

Ctrl+C / Ctrl+V — копия. Alt + тянуть стрелку — копия со сдвигом (идеально для ряда стен). Ctrl+G — сгруппировать выбранное (дом целиком), Shift+G — разгруппировать. Группу двигайте как одно целое, иначе пол уедет без стен. Для повторяющихся стен используйте Alt-дубликаты — быстрее и ровнее.

💡
Совет: привязка к сетке

Вверху Viewport иконка магнита → Grid Snap 10 см для мебели, 50–100 см для стен. Вращение — Angle Snap 90°. Без снапа стены встают на 397.3 см и дают щель в 3 мм, в которую виден свет и проваливается взгляд.

Static Mesh простыми словами

ПараметрЧто значитЧто поставить новичку
Collision PresetПроходим или упираемся. BlockAll — стена, OverlapAll — триггер, NoCollision — призракСтены/пол — BlockAll. Декор за стеклом — можно NoCollision
Materials (Element 0,1…)«Краска» меша. Один меш может иметь 2 материала (стена + плинтус)Не трогайте, пока не прошли урок про материалы
Mobility (Static/Stationary/Movable)Можно ли двигать в игре. Дом — Static (быстро + запекается)Всё в доме — Static. Дверь на Blueprint — Movable
LODУпрощённые версии для дали (меньше треугольников)Оставьте Auto. Не отключайте — упадет FPS
Cast ShadowОтбрасывает ли теньСтены — вкл. Мелкий декор внутри — можно выкл для FPS

Collision бывает: Simple (коробка/капсула вокруг — быстро, для стен), Complex (точно по треугольникам — медленно, для статуй), Custom (свой UCX_ в Blender). Если игрок проходит сквозь стену — у меша нет Simple Collision: откройте меш двойным кликом → сверху Collision → Add Box Simplified Collision → Save.

Строим двухэтажный дом: 12 шагов

Размеры: комната 800×800 см, высота этажа 300 см, толщина стен 20 см. Сетка 100 см. Все Location — кратные 100!

1

Пол первого этажа

SM_Floor 800×800×20, Location (0,0,0). Collision BlockAll, Mobility Static. Это «ноль» дома — все стены будут от него плясать.

2

Стены первого этажа

4 стены 800×300×20: север (0,400,150), юг (0,-400,150), запад (-400,0,150, поворот 90°), восток (400,0,150, поворот 90°). Alt-дублируйте, не создавайте заново. Z=150 потому что высота 300/2.

3

Углы

Если стены 800 и стыкуются торцами — углы перекроются. Либо укорачивайте боковые до 760, либо ставьте угловые столбы 20×20×300. Проверьте сверху (вид Top): не должно быть нахлёста зигзагом.

4

Окна

Два способа: а) стена с готовым проёмом SM_WallWindow из Mod Kit — просто замените целую стену; б) составная: подоконник 0–100 см + перемычка 220–300 см + 2 боковых куска. Проём 150×120 см. Не вырезайте дырки в целой стене масштабом — испортите Collision.

5

Дверной проём

Оставьте дыру 120×220 см в южной стене (2 куска + перемычка сверху). Саму открывающуюся дверь сделаем в уроке головоломок на Blueprint + Timeline. Сейчас — только проём, иначе дверь будет вмурована.

6

Потолок / пол второго этажа

Плита 800×800×20 на Z=310 (300 высота + 10 половина толщины). Это потолок первого и пол второго одновременно.

7

Лестница

SM_Stairs из Kit или 10 ступеней 100×25×18 друг над другом со сдвигом 25 см. Уклон ~35°. Обязательно Collision BlockAll каждой ступени + перила (тонкие коробки), иначе падаете. Ширина 120 см.

8

Второй этаж

Те же 4 стены, но Z=460 (310+150). Оставьте проём для выхода с лестницы 120×250 см в полу (соберите пол из 2 плит с дырой, а не целой!).

9

Крыша

Простая двускатная: 2 плиты 500×500×15 под углом 30° + торцевые треугольники (или коробки). Конёк на Z≈750. Свес 50 см за стены — иначе дождь (визуально) льёт по стенам. Mobility Static, Cast Shadow вкл.

10

Освещение

По Point Light в центре каждой комнаты (Intensity 1000, Radius 600, Stationary) + Spot над входом снаружи. См. пресеты в основах. После — Build Lighting.

11

Мебель

Кровать, стол, шкаф из Kit. Grid Snap 10 см. Шкаф с ключом внутри — задел под головоломку. Тяжёлую мебель — Static, стул который можно толкать — Movable + Simulate Physics (осторожно с лагами).

12

Collision-контроль

Play → обойдите весь дом вплотную к стенам, запрыгните на лестницу, попробуйте выйти сквозь окно/дверь. Нигде не должны проваливаться. Если проходите — у того меша NoCollision (чинится в редакторе меша).

Два подхода: готовый vs свой

Дом из готовых объектов Mod KitПолностью собственный дом
СкоростьВечер — и дом готов3–7 дней (моделинг + импорт)
СтильКак в оригинале Hello Neighbor — игрок сразу «дома»Уникальный, но риск «пластилина» без опыта
Collision/LODУже настроеныНастраиваете сами (см. импорт)
Когда братьПервый мод, хоррор-карта, учёбаСвой визуал, портфолио, конкурс

Рекомендация: первый дом — из готовых. Второй — гибрид: коробка из Kit + свои декор-меши (см. телевизор в уроке 7).

Pivot, Snap, сетка и щели

  • Pivot: у стены должен быть в углу/центре основания. Если Pivot в центре стены — привязка пляшет. Меняется в редакторе меша: Import → Transform → Pivot или правый клик → Pivot Offset в сцене (временно).
  • Snap: стены — 100 см, мебель — 10 см, поворот — 90°. Кнопки магнита вверху Viewport.
  • Щели: видны как полоски света. Лечатся снапом + проверкой вида Top + нахлёстом 1–2 см (стена 802 вместо 800 — нахлёст прячет щель, глаз не заметит).
  • Неправильный Collision: ящик 100 см, а упираетесь за 20 см до него? У него коробка Collision больше модели. Откройте меш → видно красный каркас — пересоздайте Simplified Collision.
⛔
Частая ошибка: масштаб стен 1.13

Растянули стену мышью «на глаз» — получили Scale 1.137. Следующая стена не стыкуется. Сбросьте Scale в 1.0 и используйте меши нужной длины, либо вбивайте Scale цифрами (1.0 / 2.0).

Проверка + ошибки

  • Вид Top: прямоугольник без дыр и нахлёстов-зигзагов.
  • Play: обежали дом снаружи и внутри, поднялись по лестнице, не застряли.
  • Build Lighting без «Lighting needs to be rebuilt».
  • Группа дома (Ctrl+G) двигается целиком, Pivot у пола.
Вижу свет сквозь стык стен

Щель 1–5 мм. Включите Grid Snap 10, подтяните стену, сделайте нахлёст 2 см. После — пересоберите свет.

Прохожу сквозь пол второго этажа

У плиты NoCollision или она из декора. Поставьте BlockAll. Если пол из 2 кусков с дырой под лестницу — проверьте каждый кусок.

Лестница: застреваю на середине

Ступени слишком высокие (>25 см) или без перил падаете. Уменьшите высоту, добавьте боковые Collision-стены.
