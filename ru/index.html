С чего начать и что нужно установить

Actor — любой объект, который можно разместить на уровне: стена, лампа, дверь, триггер.

Component — часть Actor, отвечающая за функцию: модель (Static Mesh), столкновение (Collision), свет, звук.

Чтобы повторять уроки, вам понадобится:

  • Epic Games Launcher + Hello Neighbor Mod Kit (вкладка Modding / поиск «Hello Neighbor Mod Kit»). Размер ~13 ГБ, движок Unreal Engine 4.20.3.
  • Игра Hello Neighbor в Steam — нужна для запуска и загрузки модов из Workshop. Сам Mod Kit запускается из Epic Launcher кнопкой Launch.
  • ПК с Windows 10/11, минимум 8 ГБ ОЗУ (лучше 16 ГБ), видеокарта с поддержкой DirectX 11.
  • Желательно мышь с колесом — без неё крайне неудобно летать по Viewport.
1

Установка Mod Kit правильно

1. Установите Epic Games Launcher, создайте аккаунт.
2. Откройте раздел Unreal Engine → Modding или вбейте в поиск Hello Neighbor Mod Kit.
3. Нажмите Install, выберите диск с запасом 20+ ГБ.
4. После установки нажмите Launch. Первый запуск долгий — компилируются шейдеры, это нормально.
5. При создании мода используйте Edit → Plugins → New Plugin, как описано в гайде ModDB «Hello Neighbor Modding Guide». Свой уровень и ассеты держите внутри папки плагина, иначе мод не упакуется.

2

Как играть и делиться модом

В Mod Kit нажмите Play (Alt+P) для теста. Для публикации: Edit → Plugins → найдите свой плагин → Package, затем Upload to Steam Workshop (нужен запущенный Steam с купленной игрой). Игроки подписываются на мод в Workshop игры (App 521890) — мод появится в игре. Альтернатива — .zip с .pak из ModDB.

⚠️
Важно: не путайте UE5 и Mod Kit

Многие уроки в интернете — для Unreal Engine 5 (Lumen, Nanite, Sky Atmosphere по-новому). Mod Kit — это UE 4.20.3: там нет Lumen, World Partition, Enhanced Input. Если видите в туториале ноды которых нет — ищите аналог для 4.20, мы везде даём такие пометки.

Совет: как не запутаться в названиях

Если в уроке для UE5 написано «добавьте Fog → Volumetric», а у вас такого нет — добавьте Exponential Height Fog из вкладки Place Actors → Visual Effects. Принцип тот же, название другое. Мы в каждом уроке даём оба названия, где это важно.

Маршрут обучения (по вечерам)

  • День 1: index + basics — создайте пустую карту с небом и холмом. Нажмите Play и побегайте.
  • День 2: building — постройте комнату 4×4 м и второй этаж. Проверьте Collision.
  • День 3: blueprints-basic — соберите куб, который уезжает от игрока. Поймите Branch и Timeline.
  • День 4: puzzles — дверь с ключом + доски с ломом. Это ядро Hello Neighbor.
  • День 5: water + day-night — бассейн с акулой и сутки за 5 минут.
  • День 6: custom-assets + blueprints-advanced — свой телевизор и генератор с лампами.
  • День 7: custom-neighbor + упаковка мода в Workshop / .pak.

Частые вопросы новичка

Где брать объекты дома Соседа? Не хочу моделить с нуля

В Content Browser Mod Kit ищите папки игры (обычно Content / HelloNeighbor): там Static Mesh стен, дверей, мебели, BP_Door, BP_Key, BP_NeighborCharacter, зоны BP_Area*. Перетаскивайте их на сцену. Свой дом с нуля — второй этап, когда поймёте пропорции.

Я открыл карту, а всё розовое / чёрное. Что делать?

Розовое = нет материала/текстуры (см. ошибки). Чёрное после Build = нет Lightmass Importance Volume или свет Static без запекания. Добавьте Lightmass Importance Volume вокруг дома и перестройте свет на Production.

Blueprint не работает. С чего начать проверку?

1) Стоит ли Blueprint на уровне? 2) Event BeginPlay вообще вызывается? (повесьте Print String). 3) Нет ли Accessed None? (поставьте Is Valid). 4) Collision на Overlap, а не Block? Полный чек — в справочнике ошибок.
