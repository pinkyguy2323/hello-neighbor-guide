4. Вода, акула и механика слива воды

Делаем бассейн с прозрачной водой, запускаем акулу-охотника на простых триггерах и собираем головоломку «вентиль → вода уходит → проход открыт». Честно разбираем, чего нет в Mod Kit из коробки и как обойти.

Что мы сделаем

Бассейн 10×6×2 м: кафельные стены, поверхность воды (полупрозрачный Plane с анимацией), объём под водой (Post Process синий), акула BP_Shark (патруль → погоня → атака → возврат), вентиль BP_Valve (вода опускается за 8 сек, акула отключается, открывается проход с ключом).

⚠️
Важно: ограничения Mod Kit 4.20.3

Готовой системы плавания (как в новых UE) и NavMesh-плавания под водой в Mod Kit нет. AI Соседа заточен под дом (BP_Area*), а не под воду. Поэтому акулу делаем учебную: Pawn/Actor + Trigger + MoveTo/Timeline, без полноценного pathfinding. Для мода этого достаточно и это честно работает.

Создание воды и бассейна

1

Чаша бассейна

Пол 1000×600×20 + 4 стены высотой 200 см (вода будет 150 см). Материал — кафель (светло-голубой, Roughness 0.3). Collision BlockAll везде. Лестница из 4 ступеней в углу. Положите на дно ящик с «сокровищем» (ключ-картой) — ради него игрок и полезет к акуле.

2

Поверхность: Plane + материал воды

Place Actors → Basic → Plane 1000×600 на высоту 150 см (Z воды). Назначьте M_Water из Kit или создайте свой (см. ниже). В Details Plane: Collision = NoCollision (иначе игрок будет «стоять» на воде!), Cast Shadow = false, Mobility = Movable (будем опускать при сливе).

3

Материал воды за 5 минут

Content Browser → Add New → Material → M_MyWater. В редакторе: Blend Mode = Translucent, Opacity 0.5–0.7, Base Color светло-голубой, Metallic 0.1, Roughness 0.1 (отражения!), Normal — волна (Panner + NormalMap, Speed 0.05). Нода Panner двигает текстуру — вода «течёт». Для ряби добавьте второй Panner в другую сторону. Сохраните → назначьте на Plane.

4

Объём воды: Post Process под водой

Добавьте Post Process Volume размером с чашу (Unbound=false, только внутри!). Настройки: синий Tint, Saturation 1.2, Exposure 0.9. Когда игрок внутри — экран синеет. Второй большой Post (на всю карту, Unbound=true) — обычная цветокоррекция. Не перепутайте!

Игрок в воде: 3 варианта

  • Вариант А (простой, рекомендуем): «брод». Игрок просто ходит по дну (вода — визуал). Замедлите его в объёме: Trigger Volume в бассейне → Set Max Walk Speed 150 (было 400) на входе, вернуть 400 на выходе. Прыжки ниже. Дёшево и работает.
  • Вариант Б: «плавание» через Blueprint. В том же триггере включите Swimming?: отключите гравитацию (Gravity Scale 0.3), разрешите «лететь» (Fly Mode) пока внутри. В 4.20 Character Movement умеет Swim, но без анимаций — персонаж будет «стоять» в воде. Приемлемо для мода.
  • Вариант В: честно никак. Полноценного плавания с анимациями и всплытием в Mod Kit нет. Не обещайте игрокам «как в GTA». Скажите «брод с замедлением» — и это будет правдой.
💡
Совет: урон воды

Хотите страх? В триггере бассейна каждые 2с отнимайте 5 HP через Apply Damage, пока игрок внутри без... ничего. А после слива — урон выкл. Игрок спешит к вентилю — геймплей!

Акула: охотник на Trigger + MoveTo

Состав BP_Shark: Skeletal/Static Mesh акулы (или конус-заглушка на первое время!) + Sphere Collision (агро 1200 см) + Box (атака 150 см). Переменные: PlayerInWater? (bool), SharkActive? (bool=true), HomeLocation (vector), Speed 300.

1

Патруль: туда-сюда по Timeline

Timeline 6с Loop: Lerp A(-400,0,0) → B(400,0,0) относительно центра бассейна → SetActorLocation + SetActorRotation по направлению. Акула плавает восьмёркой, пока игрока нет. HomeLocation запомните на BeginPlay.

2

Обнаружение: большой триггер

OnBeginOverlap (AgroSphere) → Cast To Player → если Player в воде И SharkActive → Set Chasing=true → Play Sound (Jaws-стиль). OnEndOverlap → Chasing=false. Не используйте AI Perception — в Mod Kit он капризный, триггера хватает.

3

Погоня: MoveTo без NavMesh

Event Tick → Branch [Chasing && SharkActive] → true: направление = PlayerLocation - SharkLocation (только X/Y, Z фиксируем на глубине!) → Lerp/ Move + SetActorLocation с Speed*DeltaTime → смотреть на игрока (Look At, только Yaw). Границы: Clamp X/Y в пределах бассейна — иначе акула выплывет на газон. Вариант «по-взрослому» — AI MoveTo с NavMesh Bounds Volume, но под водой NavMesh в 4.20 почти не работает, поэтому Tick+Clamp надёжнее.

4

Атака и возврат

Малый Box Overlap → Apply Damage 50 + отброс игрока (Launch Character) + звук укуса + Delay 2с (кулдаун). Если игрок вышел из воды (EndOverlap большого триггера ИЛИ Player.Z > уровня воды): Chasing=false → Timeline возврата к HomeLocation → resume патруль.

↓ true
Dir = Player − Shark (Z=0) → Normalize → × Speed × DeltaTime
↓
SetActorLocation (Clamped) + SetActorRotation (LookAt Yaw)
↓ рядом?

⚠️
Не выходит за пределы воды!

После каждого SetActorLocation делайте Clamp: X в [-450,450], Y в [-250,250] (под ваш бассейн). Иначе при лаге акула окажется в доме. Z — константа глубины (дно +80 см).

Слив воды: вентиль + Timeline

Головоломка: игрок крутит вентиль на бортике → вода уходит за 8 сек → акула «задыхается» (отключается) → проход на дне открывается. Переменные: WaterLevel (float 1.0→0.0), WaterDrained (bool).

1

Вентиль BP_Valve

Mesh вентиля (тор) + Sphere Trigger. На E: Branch [WaterDrained? уже слита?] → false: Play TL_Drain (8с) + звук скрипа/воды + вращение ручки (SetRelativeRotation 0→720° по тому же Timeline). Do Once — чтобы не сливать дважды.

2

Timeline слива: опускаем воду

TL_Drain: Float 1→0 за 8с. Update: WaterLevel = Lerp → WaterPlane.SetActorLocation (Z = дно + WaterLevel*150см) → WaterPlane.Set Scalar Opacity (прозрачнее по мере слива) → если WaterLevel<0.05: WaterDrained=true. Параллельно опускайте и Post Process Volume (или отключите его в конце: Set Enabled=false).

3

Отключаем акулу и открываем проход

На WaterDrained=true (Event Dispatcher или прямая ссылка): Shark.SharkActive=false + Chasing=false → Play анимация «бьётся на суше» (Rotate Z ±20° быстро 2с) → затем Stop → открыть Collision прохода на дне (Set Collision NoCollision + сдвинуть крышку) → показать ключ. Добавьте Print «Вода слита! Акула больше не опасна.»

E на Valve → DoOnce → Play TL_Drain (8с)
↓ Update каждый кадр
WaterLevel 1→0 → Set Water Z + Opacity
↓ Finished
Set WaterDrained=true → SharkActive=false → открыть Collision прохода
SetActorLocation для воды — двигаем именно Plane, а не весь бассейн! Z = Lerp(дно, верх, WaterLevel). Не забудьте Movable у Plane.
Set Collision Enabled — у крышки прохода переключаем BlockAll → NoCollision. Игрок проваливается вниз за наградой. Обратно — не надо, это финал.
WaterDrained — главный флаг уровня. Его же читают акула (не гоняться), урон воды (не тикать), Widget (сменить подсказку).

Проверка + ошибки

  • Play: вода полупрозрачная, видно дно, под водой синий экран.
  • Зашли в бассейн — скорость упала, акула поплыла к вам.
  • Вышли — акула вернулась в центр, не выплыла на траву.
  • Покрутили вентиль — вода ушла за ~8с, акула замерла, проход открылся.
  • Повторный E на вентиль ничего не ломает (DoOnce).
Хожу по воде как по полу

У Plane стоит BlockAll. Поставьте NoCollision. Проверьте и у Post Process — у него вообще не должно быть Collision.

Акула вылетает из бассейна / в небо

Не зафиксировали Z и нет Clamp. Z = константа, X/Y через Clamp под размер бассейна. В Tick умножайте на DeltaTime, иначе скорость зависит от FPS.

Вода не опускается

Plane — Static (должен быть Movable) или Timeline не Play, а Reverse. Проверьте Update-пин соединён с SetActorLocation.

Акула продолжает бить после слива

Не проверяете WaterDrained в Tick. Добавьте Branch [NOT WaterDrained] перед погоней и SharkActive=false в финале слива.
