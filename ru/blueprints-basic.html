5. Blueprint для новичков

Разбираем визуальное программирование с нуля: что такое Actor и ноды, какого цвета провода, 16 главных нод с примерами и практика «куб убегает от игрока». После урока вы будете читать схемы из головоломок как текст.

Что мы сделаем

Создадим BP_MagicCube: игрок входит в Trigger → куб отпрыгивает в сторону → ждёт 2 сек → возвращается. По пути выучим все базовые ноды и научимся отличать белый провод выполнения от цветных проводов данных.

Важно: белые провода — главные

Новичок соединяет цветные пины и удивляется, что ничего не происходит. Логика выполняется только по белым стрелкам! Сначала проведите белый путь Event → действие, потом подайте данные в цветные пины.

16 главных нод: что делает, пример, ошибка

1. Event BeginPlay — «когда уровень начался»

Делает: срабатывает один раз при старте игры для каждого актора.
Пример: запомнить HomeLocation акулы, показать «Найдите ключ».
Ошибка: ставите в Construction Script вместо BeginPlay — выполняется в редакторе, в игре молчит. Или BeginPlay на акторе, которого нет на уровне (лежит в папке, но не поставлен).

2. Event Tick — «каждый кадр»

Делает: выполняется ~60 раз/сек. Для погони, проверки дистанции.
Пример: акула каждый Tick ползёт к игроку.
Ошибка: вешаете тяжёлое (Spawn, Delay, Print) на Tick — лаги и спам. Ставьте Branch-фильтр и по возможности таймеры вместо Tick.

3. Branch — «если… то… иначе…»

Делает: развилка по Boolean. True → верх, False → низ.
Пример: HasKey? true → открыть, false → «Нужен ключ».
Ошибка: подали Integer вместо Boolean (нужен Equal перед Branch).

4. Delay — «подожди N секунд»

Делает: пауза в белой цепочке. Duration 2.0.
Пример: куб ждёт 2с перед возвратом.
Ошибка: Delay на Tick (накапливаются сотни задержек) или ждёте точную паузу при лагах (Delay не точный таймер).

5. Print String — «напиши на экране»

Делает: отладка: текст в углу + в лог. Key «1» чтобы не спамило.
Пример: Print HasKey после подбора ключа.
Ошибка: забыли убрать 20 Print перед упаковкой — экран в мусоре. Для игрока используйте Widget (урок 6).

6–7. Set / Get — «положи / возьми»

Делают: Set меняет переменную, Get читает. Перетащите переменную в граф с зажатым Ctrl (Set) / Alt (Get).
Пример: Set HasKey=true при подборе.
Ошибка: Set не той копии (у двери №2, а открываете №1).

8. Sequence — «сделай по порядку»

Делает: выполняет Then 0, потом Then 1. Удобно: сначала звук, потом анимация.
Ошибка: думаете, что Then 1 ждёт конца Then 0 — нет, идут почти сразу. Для ожидания — Delay/Timeline между.

9. Do Once — «только один раз»

Делает: пропускает сигнал раз, дальше глухо, пока не Reset.
Пример: вентиль слива, подбор ключа.
Ошибка: забыли Reset когда надо повторно (дверь открывается раз за игру — ок, а ловушка должна сбрасываться).

10. FlipFlop — «туда-сюда»

Делает: 1-й вызов → A, 2-й → B, 3-й → A…
Пример: E открывает/закрывает дверь.
Ошибка: два FlipFlop подряд дают рассинхрон (дверь открыта, а логика думает закрыта). Один FlipFlop на дверь!

11. Timeline — «анимация по времени»

Делает: кривая 0→1 за N сек, пины Play/Reverse/Update/Finished.
Пример: дверь 0→90°, вода 1→0.
Ошибка: меш Static вместо Movable; длина 0; Update не подключён.

12. Cast To — «ты случайно не игрок?»

Делает: проверяет класс + даёт доступ к его переменным (As…).
Пример: Cast To BP_Player → Get HasKey.
Ошибка: Cast Failed (это был стул, не игрок) — всегда обрабатывайте пин Failed или ставьте IsValid.

13. Is Valid — «ты существуешь?»

Делает: проверка ссылки на None. Is Valid → ветка, Is Not Valid → заглушка.
Пример: перед Get Player в двери.
Ошибка: отсутствие IsValid = Accessed None в 90% случаев.

14–15. Destroy / Spawn Actor — «удалить / создать»

Делают: Destroy убирает актор (ключ подобран), Spawn создаёт (заспавнить доску заново). Spawn нужен Class + Transform.
Ошибка: DestroyPLAYERа вместо ключа (проверяйте Target!) или Spawn без Collision — объекты внутри друг друга взрываются физикой.

16. SetActorLocation / Rotation + Play Sound

Делают: двигают/крутят актор, играют звук в точке.
Пример: акула плывёт, дверь крутится, вентиль скрипит.
Ошибка: двигаете Static (нужен Movable) или забываете DeltaTime в Tick (скорость зависит от FPS).

Практика: куб убегает от игрока

1

Создаём BP_MagicCube

Add New → Blueprint Class → Actor → BP_MagicCube. Компоненты: Static Mesh Cube (Movable, BlockAll) + Box Collision 400 (OverlapAllDynamic). Переменные: Home (Vector), IsAway (Bool=false). На BeginPlay: Set Home = GetActorLocation.

2

Отпрыгнул → подождал → вернулся

Граф: OnBeginOverlap → Cast To Player → IsValid → Branch [IsAway? false] → Set IsAway=true → GetActorLocation + (0,0,200)+(случайный X/Y 300) → SetActorLocation (или Timeline 0.5с для плавности) → Delay 2.0 → SetActorLocation (Home) → Set IsAway=false. Без IsAway куб будет дёргаться при каждом Overlap.

OnBeginOverlap → Cast To Player → IsValid
↓
Branch IsAway? (false → дальше, true → стоп)
↓
Set IsAway=true → SetActorLocation (вверх+вбок)
↓
Delay 2.0 → SetActorLocation (Home) → Set IsAway=false

Как проверить: Play → подойдите → куб прыгает, через 2с возвращается. Подойдите 5 раз подряд — не должно задвоиться (спасибо IsAway). Удалите IsAway ради эксперимента — увидите баг «дёрганья» и поймёте, зачем флаги.

Проверка + ошибки

  • Print String показывает HasKey=true после подбора.
  • BeginPlay срабатывает (видно по Print), Tick не спамит.
  • Cast идёт к правильному классу, стоит IsValid.
  • Куб возвращается ровно в Home, а не «примерно туда».
Event BeginPlay не работает

Актор не на уровне, а в папке; или BeginPlay в Construction Script; или Level Blueprint перекрывает GameMode. Поставьте Print в самое начало BeginPlay — если молчит, актора нет на сцене.

Accessed None

Пустая ссылка (игрок удалён, дверь не назначена). Поставьте IsValid перед каждым Get чужой переменной. См. справочник.
