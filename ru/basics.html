1. Основы карты: небо, свет и рельеф

Создаём первый уровень с нуля: разберём 4 главных окна редактора, поставим солнце и небо, настроим дневной и ночной свет, выкопаем холм, дорогу и площадку под дом. В конце — почему персонаж проваливается и как это чинить за 2 минуты.

Что мы сделаем

К концу урока у вас будет уровень MyFirstMap: голубое небо, солнце с мягкими тенями, туман у горизонта, участок земли 63×63 м с холмом, грунтовой дорогой, ямой и ровной площадкой 12×12 м под будущий дом. Вы сможете нажать Alt+P (Play) и побегать от третьего/первого лица без провалов.

Уровень (Level / Map) — файл .umap со всей сценой: земля, дома, свет, точки спавна. Viewport — 3D-окно, где вы летаете. World Outliner — список всех объектов уровня. Details — настройки выбранного объекта. Content Browser — файловый менеджер всех ассетов игры.

Что понадобится

  • Открытый Hello Neighbor Mod Kit (UE 4.20.3).
  • Пустой плагин мода (Edit → Plugins → New Plugin) — карту делаем внутри него, например Plugins/MyMod/Content/Maps/MyFirstMap.umap.
  • 10–15 минут на компиляцию шейдеров при первом запуске — не пугайтесь «подвисшего» редактора.
  • Режим Place Actors (слева): вкладки Basic, Lights, Visual Effects, Volumes.

Окна редактора: 4 главных панели

1. Viewport — ваш глаз

Большое 3D-окно по центру. Вверху кнопки: Perspective / Top / Front / Side (вид), Lit → Unlit / Wireframe (режим отображения), скорость полёта (иконка человечка). Если сцена чёрная — вы в режиме Unlit или камера под землёй, нажмите F чтобы сфокусироваться на объекте.

2. Content Browser — склад

Нижняя панель. Здесь папки Content игры и вашего плагина. Кнопка Add New создаёт Blueprint/Material/Level. Строка поиска + фильтр по типу (Static Mesh, Material, Blueprint). Правый клик → Show in Explorer покажет файл на диске. Никогда не таскайте .uasset через Windows-проводник — сломаете ссылки, используйте Migrate.

3. World Outliner — список

Правая верхняя панель. Каждый объект уровня строкой: DirectionalLight, SkyLight, Landscape, PlayerStart. Глазик — видимость, поиск — фильтр. Если потеряли объект — кликните по нему в Outliner и нажмите F.

4. Details — настройки

Правая нижняя панель. Показывает всё выбранное: Transform (Location/Rotation/Scale), Light (Intensity, Color), Collision. Строка поиска вверху Details — ваш лучший друг: вбейте Intensity вместо листания 200 параметров.

💡
Совет: верните потерянную панель

Закрыли Content Browser? Window → Content Browser → Content Browser 1. Пропал Outliner? Window → World Outliner. В Mod Kit раскладка сбрасывается через Window → Reset Layout.

Создание и сохранение карты

1

Создаём пустой уровень

File → New Level → Empty Level (не Default — там уже стоит лишнее освещение, которое запутает). Вы увидите чёрный Viewport с сеткой — это нормально, света пока нет.
Где находится: верхнее меню File. Что выбрать: именно Empty. Default тянет готовый Sky и пол, которые потом дублируются.

2

Сохраняем с правильным именем

File → Save Current As… → перейдите в папку своего плагина /Mods/ВашМод/Content/Maps/ → имя MyFirstMap без пробелов и русских букв (только латиница, цифры, _). Пробелы ломают упаковку в .pak и ссылки в Blueprint (потом «Failed to load»).
Нажимайте Ctrl+S каждые 5 минут. Mod Kit 4.20 любит вылетать на слабых ПК при Build.

3

Ставим точку спавна

Из Place Actors → Basic → Player Start перетащите в центр карты. Поднимите на 100 см над землёй (Location Z +100), иначе появитесь под ландшафтом. Без Player Start кнопка Play спавнит вас в 0,0,0 — часто внутри земли.

⛔
Частая ошибка: карта вне плагина

Сохранили в Content/Maps самого Mod Kit, а не в свой плагин? При Package мод будет пустым. Перенесите через Content Browser: правый клик → Move To → папка плагина.

Location — координаты X/Y/Z (где стоит). Rotation — поворот в градусах (дверь на 90°). Scale — размер (1.0 = оригинал, 2.0 = вдвое больше). Меняйте или стрелками в Viewport, или цифрами в Details — цифры точнее.

⚠️
Главная путаница: W/E/R

С зажатой ПКМ WASD — полёт. С отпущенной ПКМ W/E/R — режимы гизмо. Если нажали W и объект не двигается стрелками — вы просто летите. Отпустите мышь и нажмите W ещё раз.

Небо: ставим солнце и атмосферу

Небо в UE — не «картинка», а связка из 5 акторов. Добавляйте через Place Actors → Lights / Visual Effects перетаскиванием на сцену:

1

Directional Light — солнце

Это параллельные лучи «бесконечного» солнца. Поверните: Rotation Y ≈ -50° (высота), Z ≈ 30° (азимут). Intensity для дня 3.0–5.0, цвет чуть тёплый #FFF2DF. Галочка Cast Shadows — вкл. Именно этот свет даёт длинные тени от дома, как в Hello Neighbor.
Где искать: Place Actors → Lights → Directional Light.

2

Sky Light — свет неба

Мягкая заливка со всех сторон, чтобы тени не были чисто чёрными. Details → Source Type → SLS Captured Scene, Intensity 1.0. Без Sky Light ночь и interiors выглядят «плоскими».

3

Sky Atmosphere + Exponential Height Fog — воздух

Sky Atmosphere (Visual Effects) — голубое небо и горизонт. Exponential Height Fog — дымка вдали: Density 0.01–0.03 для дня, 0.05 для утра. Если в вашей сборке Mod Kit есть старый Atmospheric Fog вместо Sky Atmosphere — используйте его, принцип тот же: Density 0.3–0.6. Оба сразу не нужны — будет пересвет.
Версия: ранние Mod Kit (4.18/4.19) шли с Atmospheric Fog, финальный (4.20.3) — уже со Sky Atmosphere. Проверьте что есть у вас через поиск в Place Actors.

4

Post Process Volume — цветокор

Place Actors → Visual Effects → Post Process Volume. В Details включите Infinite Extent (Unbound) = true, иначе эффект только внутри куба. Для старта: Exposure 1.0, Saturation 1.1, чуть тёплый White Balance. Под водой позже сделаем второй Volume с синим оттенком (см. урок про воду).

💡
Совет: быстрый пресет неба

День: Directional 4.0 тёплый, Sky 1.0, Fog 0.015. Закат: Directional 2.0 оранжевый #FF9A3C, угол Y -12°, Fog 0.04. Ночь: Directional 0.15 синий #5A7BFF (луна), Sky 0.25. Сохраните 3 поворота солнца в блокноте — пригодятся для дня/ночи.

Освещение: типы ламп и Mobility

Point LightЛампочка: светит во все стороны из точкиЛюстра, костёр, лампа на столе. Attenuation Radius 400–800
Spot LightФонарик: конус светаФонарь над дверью, свет из окна. Outer Cone 40–60°
Sky LightНебо-заливка1 шт, всегда

Mobility: Static / Stationary / Movable — самое важное

  • Static — не двигается и не меняется в игре. Самый быстрый, запекается в Build Lighting. Для стен, солнца дневного.
  • Stationary — стоит на месте, но цвет/яркость можно менять в Blueprint (лампа, что гаснет). Компромисс.
  • Movable — можно двигать и мигать каждый кадр (фонарик игрока, rotating sun для дня/ночи). Самый «дорогой», тени в реальном времени.

Ключевые параметры в Details: Intensity (яркость; лампа 500–2000 в UE4-единицах, солнце 3–10), Light Color, Attenuation Radius (как далеко добивает Point/Spot), Source Radius (мягкость тени), Cast Shadows.

Build Lighting: когда и как запекать

Static и Stationary свет считается заранее кнопкой Build → Build Lighting Only. Без Build тени квадратные/течёт свет, выскакивает предупреждение «Lighting needs to be rebuilt». Movable в Build не нуждается.

★

Правильный Build за 4 шага

1. Добавьте Lightmass Importance Volume (Place Actors → Volumes) и растяните кубом вокруг дома/игровой зоны — иначе движок считает свет на всю бесконечность и всё тёмное.
2. Build → Lighting Quality → Preview для черновика, Medium/Production для финала.
3. Нажмите Build Lighting Only. Ждите, не трогайте редактор.
4. Если после Build всё стало тёмным — см. ошибки: чаще всего свет Static без Volume или Intensity 0.
Когда НЕ нужен Build: всё освещение Movable (но будет тяжелее для FPS).

Landscape: холм, дорога, яма, площадка

1

Создаём землю

Слева вверху Modes → Landscape → Create New. Для первой карты: Section Size 63×63, Sections Per Component 1, Overall Resolution 63×63 (маленькая быстрая карта). Material — любой M_Ground из Mod Kit или стандартный M_Landscape. Нажмите Create — появится серая земля.
Большие карты (505×505 и выше) — только когда будет дом и оптимизация, иначе лаги.

2

Инструменты Sculpt: что делает каждый

Выберите Landscape → вкладка Sculpt:
• Sculpt — поднимает/опускает (зажатый Shift — наоборот, яма). Strength 0.3, Size 800 для холма.
• Smooth — сглаживает рваные края. Пройдитесь после каждого холма.
• Flatten — выравнивает под высоту клика. Идеален для площадки под дом: кликните на нужной высоте, проведите по зоне 12×12 м.
• Noise — лёгкие неровности природы (Strength 0.05, иначе марс).
• Erosion (если есть в 4.20) — размыв дождём, делает склоны естественными.
Paint — раскраска слоями (трава/земля/асфальт), если у материала есть Layer Blend. Сначала назначьте материал с 2–3 слоями, иначе Paint нечего красить.

3

Практика: 4 формы за 10 минут

Холм: Sculpt, Size 1200, Strength 0.4, 3 клика в центре → Smooth по краям.
Дорога: Flatten узкой кистью от калитки к дому + Paint коричневым слоем, Size 300.
Яма: Sculpt + зажатый Shift, Size 500, Strength 0.5, 2 сек → Smooth.
Площадка под дом: Flatten, клик на высоте дома, закрасьте квадрат 1200×1200 см. Проверьте линейкой: стены должны стоять на ровном, иначе щели (см. строительство).

💡
Совет: Landscape Material

Простой материал земли: Layer Blend (Grass, Dirt, Rock) → BaseColor. В Paint создайте Layer Info для каждого слоя (правый клик → Create). Без Layer Info кисть красить не будет — самая частая жалоба новичков.

Почему персонаж проваливается сквозь землю

Топ-4 причины по частоте:

  1. Нет Collision у Landscape. В Details ландшафта Collision → Collision Enabled = Query and Physics, Collision Preset = BlockAll. Если стоит NoCollision — вы падаете в бесконечность.
  2. Player Start под землёй или в воздухе высоко. Поднимите на 50–150 см над поверхностью. Падение с 2000 см тоже может «прошить» тонкий пол — ставьте ближе.
  3. Масштаб Landscape ×0 или дырка от Sculpt. Слишком глубокая яма + маленькая толщина = физика не успевает. Сгладьте, поднимите персонажа.
  4. Вы тестите камерай, а не персонажем. В Play Settings стоит Spectator? Поставьте GameMode → Default Pawn = BP_PlayerCharacter из Mod Kit.

Как проверить + частые ошибки

  • Нажали Play — видно небо, солнце, тени от Player Start двигаются при вращении Directional.
  • Побегали по холму/дороге/яме — нигде не провалились, площадка ровная.
  • Build Lighting без красных ошибок, свет не «течёт» сквозь стены.
  • Карта сохранена в папке плагина, имя латиницей.
Свет слишком яркий / всё белое

Уменьшите Directional до 3.0, проверьте Exposure в Post Process (должно быть ~1.0) и не стоят ли два Directional друг на друге (удалите дубликат в Outliner).

После Build всё стало тёмным

Добавьте Lightmass Importance Volume, переключите свет на Movable для теста, пересоберите на Preview. Подробнее — справочник ошибок.

Небо чёрное днём

Нет Sky Light или Sky Atmosphere без Directional. Добавьте оба + Fog. Проверьте, что в Viewport режим Lit, а не Unlit.

Что делать, если нет Sky Atmosphere / нужной ноды?

В 4.18–4.19 используйте Atmospheric Fog. В 4.20 — Sky Atmosphere. Если нет Erosion — обойдитесь Sculpt+Smooth, результат тот же. Не ставьте плагины UE5 — они несовместимы.
