12. Своё главное меню для мода

Титульник с кнопками Играть / Как играть / Выйти: виджет W_MainMenu на UMG, OnClicked → Open Level / Remove from Parent, привязка в Level Blueprint, меню-GameMode, упаковка. По докам Epic «Creating a Main Menu» (4.27, те же ноды в 4.20) + блюпринтам меню с Reddit.

★★ СреднеНОВОЕUMG с нуля

📑 Оглавление

  1. Вёрстка виджета
  2. Логика кнопок
  3. Привязка уровня + GameMode
  4. Упаковка + бонус паузы

Вёрстка виджета (W_MainMenu)

Content Browser → Add New → User Interface → Widget Blueprint → W_MainMenu. Designer: Canvas Panel → картинка-фон (ваш арт, тёмный + заголовок «МОЙ МОД» 64px) → Vertical Box по центру → 3 Button (Играть / Как играть / Выйти) с текстом 24px, отступы 10, имена PlayButton/HelpButton/QuitButton. Якорь по центру, фокус потом на PlayButton (поддержка геймпада). Шрифты — стандартные: кастомные часто ломают кукер в 4.20.

Логика кнопок (вкладка Graph)

Выбираем PlayButton → Details → Events → + On Clicked (так для всех). OnClicked(Play) → Open Level (ваша копия акта, напр. Act1_FSpawn) → Remove from Parent (себя). OnClicked(Help) → MainMenu Hidden + HelpPanel Visible (Назад — наоборот). OnClicked(Quit) → Execute Console Command «Quit». Имя уровня — ТОЧНО как файл (регистр важен!), иначе чёрный экран — ошибка меню №1. Compile + Save.

Привязка уровня + GameMode

Меню нужна своя карта: File → New → Empty → MenuMap (чёрная комната + камера хватит). Её Level Blueprint: Event BeginPlay → Create Widget (W_MainMenu) → Add to Viewport → Get Player Controller → Set Input Mode UI Only + Show Mouse Cursor true. Без UI-Only клики пролетают в игру за меню. World Settings карты MenuMap: GameMode Override = MenuGameMode (дубликат китового GameMode с пустым пешкой-наблюдателем, чтобы никто не бегал за меню — приём из UMG-туто Epic). Project Settings → Maps & Modes → Game Default Map = MenuMap + MenuMap и акты в список карт упаковки.

⚠️
Важно: честность про Mod Kit

Моды Workshop грузятся через меню модов игры — ваш MenuMap станет входом мода, а не заменой родного титульника (это глубже, ломается обновлениями). Пишите в описании: «Запустить мод → моё меню → Играть». Моддеры Reddit подтверждают: свои Main/Pause-меню блюпринтами работают; полная замена титульника хрупкая — лучше меню-картой входа.

Упаковка + бонус паузы

Пакуем плагин с MenuMap внутри, тестируем упакованный (PIE врёт про имена Open Level!). Бонус паузы: Esc Action → Create W_Pause (Продолжить/Заново/Меню/Выйти) → Set Game Paused true + UI Only; Продолжить → Remove + Unpause + Game Only. Сосед на паузе: Set Game Paused, а не Time Dilation 0 — дилейшн ломает Timeline-двери.

Чёрный экран / клики мертвы / игрок бегает за меню?

Опечатка имени уровня (копипаст точного). Нет UI-Only + курсора. GameMode спавнит бегуна — переопределите пустой пешкой. Виджет создался дважды (двойной BeginPlay) — закройте DoOnce.
