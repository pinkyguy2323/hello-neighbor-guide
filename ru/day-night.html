6. День, ночь, таймеры и текст на экране

Делаем живые сутки: солнце вращается по Timeline, меняются цвет и туман, ночью зажигаются фонари. Плюс 3 способа показать текст: отладочный Print, красивый Widget и подсказки «Нужен красный ключ / Нажмите E».

Что мы сделаем

BP_DayNight: полный цикл 5 минут (день 2 мин → закат 1 мин → ночь 1.5 мин → рассвет 0.5 мин). Ночью включаются Point Light фонари. Подсказки: у закрытой двери — «Нужен красный ключ», с ключом — «Нажмите E». Основано на ModDB-туто #5 «Dynamic Day Night Cycle».

Автоматическая смена дня и ночи

1

Готовим солнце к вращению

Directional Light → Mobility Movable (иначе Timeline не покрутит!). Sky Light — тоже Movable. Запомните 4 поворота (Rotation Y/Pitch): день -55°, закат -12°, ночь +25° (солнце под горизонтом, светит «луна» — уменьшим Intensity), рассвет -30°. Цвет: день #FFF3E0, закат #FF7A2F, ночь #5A7BFF.

2

Timeline суток 300 сек

В BP_DayNight: Timeline TL_Day, Loop=true, длина 300. Float-трек SunAngle: ключи (0с=-55, 120с=-55, 180с=-12, 240с=+25, 270с=+25, 300с=-55). Второй трек LightColor? Проще: в Update делайте Lerp цвета по SunAngle через 3 Branch-диапазона + Set Light Color / Intensity + Set Sky Intensity + Set Fog Density. Ночью Intensity солнца 0.15–0.25, Sky 0.3, Fog 0.03.

3

Ночные фонари

Все уличные Point/Spot соберите в Array (см. массивы) или тегните Tag=NightLight. В Update: если SunAngle > 0 (ночь) → ForEach → Set Visibility true + Set Intensity 1500, иначе false. Днём фонари выкл — экономим FPS. Добавьте Emissive-материал плафона (днём серый, ночью светится) — см. телевизор в уроке 7.

BeginPlay → Play TL_Day (Loop)
↓ Update каждый кадр
SunAngle → Set Directional Rotation → Lerp Color/Intensity
↓
Если ночь → вкл NightLight[], иначе выкл + Set Fog/Sky
💡
Совет: туман и Post ночью

Ночью поднимите Fog до 0.04 и затемните Post Exposure до 0.85 — хоррор как в оригинале. Днём верните 0.012 / 1.0. Игрок физически почувствует «темнеет — пора прятаться».

Переключение кнопкой и по событию

  • Кнопкой (тест): Action Mapping ToggleNight (клавиша N) → FlipFlop → A: остановить Timeline + поставить ночь (Set Rotation/Color вручную), B: вернуть день. Удобно для скриншотов.
  • По событию (геймплей): подобрал предмет → наступила ночь. В BP_Pickup после HasKey=true вызовите Get BP_DayNight → Set NightNow=true → Timeline Jump to 240с. + Print «Что-то изменилось… стало темно». Такой приём держит напряжение: «взял ключ — сосед проснулся».
  • Таймер обратного отсчёта: Set Timer by Event (5с) → закрыть дверь / включить сирену. Не путайте с Delay: Timer можно остановить (Clear Timer), Delay — нет.

Текст: Print vs Widget

СпособКакПлюсыМинусы
Print StringНода с текстом, Duration 3с2 секунды — и готово, идеальна для отладкиУродливо, только для разработчика
UMG Widget + Text BlockВиджет на экране с красивым шрифтомКак в настоящей игре, можно кнопки/картинкиНужно создать Widget Blueprint
3D Widget над дверьюWidget Component на двериТекст «в мире», видно издалекаТяжелее, для 1–2 подсказок

Создаём Widget-подсказку с нуля

1

Widget Blueprint

Content Browser → Add New → User Interface → Widget Blueprint → W_Hint. Откройте Designer: перетащите Text Block вниз по центру, имя HintText, текст «…», размер 24, тень (Shadow), цвет белый. Якорь — низ-центр. Сохраните.

2

Показываем игроку

В PlayerCharacter или Level Blueprint на BeginPlay: Create Widget (W_Hint) → Add to Viewport → сохранить в переменную HintWidget (чтобы менять текст). Создаём один раз! Дальше только меняем текст и видимость.

3

Меняем текст у двери

В BP_Door на Overlap: Get HintWidget → Set HintText: если HasKey → «Нажмите E, чтобы открыть дверь», иначе → «Нужен красный ключ» → Set Visibility Visible. На EndOverlap: Set Visibility Hidden. После открытия: Hidden. Текст — именно Text, а не String (иначе ругается на локаль).

BeginOverlap двери → Get HasKey
↓
TRUE: SetText «Нажмите E…» | FALSE: SetText «Нужен красный ключ»
↓
Set Visibility Visible → EndOverlap: Hidden
⛔
Частая ошибка: 10 виджетов друг на друге

Create Widget в Overlap (каждый вход — новый виджет). Создавайте один раз на BeginPlay, в Overlap только SetText/Visibility. Проверьте: в игре должен быть 1 W_Hint в списке виджетов.

Проверка + ошибки

  • За 5 минут солнце проходит день→закат→ночь→рассвет без рывков.
  • Ночью фонари горят, днём — нет. Тени не квадратные (Movable!).
  • У двери без ключа — «Нужен красный ключ», с ключом — «Нажмите E».
  • N включает ночь принудительно, подбор артефакта — тоже.
Солнце не вращается

Mobility Static вместо Movable или Timeline не Loop / не Play. Проверьте Update → SetRelativeRotation соединён.

Ночью слишком темно / днём пересвет

Ночь: Intensity 0.2, а не 0. Sky 0.3 не 0. День: Exposure 1.0, Directional не 10. Крутите по одному параметру за раз.

Текст не меняется

HintWidget пустой (Create не вызван) или SetText идёт в другой виджет. Проверьте IsValid на HintWidget + Print перед SetText.
