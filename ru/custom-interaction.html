11. Свой функционал предметам — ЛКМ с предметом в руках

Держите свой предмет, жмёте ЛКМ → гудок, вспышка, бросок, лечение: маппинг Fire, проверка «держу ли» (HasItem + HeldRef + IsValid), звук + кулдаун + эффекты. Приёмы из туто ModDB про Switch и текстовые триггеры + доки UE 4.20.

Как работает «в руках» в Hello Neighbor

Подбор = Overlap → AttachToComponent (HandSocket) + HasItem=true + HeldRef=я (см. лом). Выброс = Detach + HasItem=false. Значит «ЛКМ с предметом» = проверка HasItem && IsValid(HeldRef) && HeldRef именно этого класса. Без проверки класса клик с ЛЮБЫМ предметом (и с пустыми руками) будет гудеть — классический баг. HeldRef храните Object Reference в игроке, при выбросе очищайте.

Маппинг ЛКМ (старый инпут!)

Project Settings → Input → Action Mappings → Fire = Left Mouse Button. Событие InputAction Fire (Pressed) в PlayerCharacter (именно Pressed, не Axis — Axis спамит). Только 4.20; туториалы UE5 с IA_Fire не подойдут. Тест: сначала Print «клик» на Pressed, потом логика.

Логика клика: звук + действие

1

Проверка: держу ли ЭТО?

В BP предмета (или в игроке): Fire Pressed → Get Player → HasItem? → HeldRef IsValid? → Cast HeldRef к MyItemClass? да → дальше; нет → ничего (или звук пустого клика). Логику кладите в ПРЕДМЕТ, если особенный один; в ИГРОКА со Switch по классу, если предметов с ЛКМ много.

2

Делаем: звук + кулдаун

→ Play Sound at Location (гудок в позиции предмета, не 2D — 2D не знает дистанции) → вспышка (Emissive вкл / Spawn Emitter в сокете) → Do Once + Retriggerable Delay 0.4с (анти-пулемёт) → заряды-- → 0 = сломался (Detach + Destroy + HasItem=false). Sound Cue из кита или пак ALL SOUNDS PACK с ModDB (кидаете .uasset в HelloNeighbor/Content, потом Migrate в свой мод — совет Zxenook).

InputAction Fire → HasItem? → HeldRef валиден? → Cast MyItem?
↓ да
Play Sound at Location + вспышка → кулдаун 0.4с → заряды-- → 0 = потрачен
Cast HeldRef — проверка личности («именно этот гудок, а не ключ»). At Location vs 2D — Location направленный/громкий рядом (Сосед УСЛЫШИТ! AI придёт проверять — отличный геймплей); 2D = писк интерфейса. Кулдаун — 60 кликов/сек топят звуковой пул. Заряды — int, в ноль → потрачен, как доски.

5 идей функционала (берите одну, потом комбинируйте)

1) Горн-пугалка: громкий звук + Make Noise (Loudness 1.0) → Сосед идёт проверять (родной слух AI). 2) Фонарик по клику: Toggle Spot Visible + Emissive (нужен Stationary/Movable, см. приём телевизора с Dynamic Instance). 3) Бросок: Detach + Add Impulse Forward×1500 + HasItem=false (лом-бумеранг!). 4) Использование: заряды-- → лечение / открыть связанную дверь через Interface (урок 8). 5) Комбо: ЛКМ = звук, удержание 1с (время зажатия + Timeline) = мощный залп. Различайте Pressed и Released: заряд на Pressed, сила по времени на Released.

Стреляет с пустыми руками / нет звука / пулемёт / AI игнорит?

Добавьте проверку класса HeldRef. Cue битый → проверьте китовый Cue; Location нужен attenuation. Кулдаун 0.3–0.5с + DoOnce. Для AI: Make Noise / громкий Location рядом с Соседом + зоны Area на месте.
