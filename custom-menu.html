12. Custom main menu for your mod

Title screen with Play / How to play / Quit: W_MainMenu UMG widget, OnClicked → Open Level / Remove from Parent, Level Blueprint BeginPlay wiring, menu GameMode, packaging. Follows Epic “Creating a Main Menu” (4.27, same nodes in 4.20) + Reddit modders' Main/Pause menu blueprints.

MediumNEWUMG from zero

📑 Contents

  1. Widget layout
  2. Buttons logic
  3. Level wiring + GameMode
  4. Package & pause bonus

Widget layout (W_MainMenu)

Content Browser → Add New → User Interface → Widget Blueprint → W_MainMenu. Designer: Canvas Panel → Background Image (your art, dark + title “MY MOD” 64px) → Vertical Box centered → 3 Buttons (Play / How to Play / Quit) each with Text child 24px, padding 10, names PlayButton/HelpButton/QuitButton. Anchor center, keyboard focus later to PlayButton (gamepad support). Keep fonts default — custom fonts often break cooker in 4.20.

Buttons logic (Graph tab)

Select PlayButton → Details → Events → + On Clicked (repeat for all). OnClicked(Play) → Open Level (your Act copy, e.g. Act1_FSpawn) → Remove from Parent (self). OnClicked(Help) → Set MainMenu Hidden + HelpPanel Visible (Back reverses). OnClicked(Quit) → Execute Console Command “Quit”. Open Level name must match EXACTLY (case-sensitive!) or you get black screen — #1 menu bug. Compile + Save.

Level wiring + GameMode

Menu needs its own map: File → New → Empty → MenuMap (a black room + camera is fine). Its Level Blueprint: Event BeginPlay → Create Widget (W_MainMenu) → Add to Viewport → Get Player Controller → Set Input Mode UI Only + Set Show Mouse Cursor true. Without UI-Only mode clicks fall through to the game behind the menu. World Settings of MenuMap: GameMode Override = MenuGameMode (duplicate of kit GameMode with default pawn = Spectator/None so nobody runs behind the menu — Epic UMG tutorial pattern). Project Settings → Maps & Modes → Game Default Map = MenuMap + add MenuMap + Act maps to Packaging map list.

⚠️
Mod Kit honesty

Workshop mods load through the game's mod menu — your MenuMap becomes the mod's entry, not a replacement of the shipping title screen (that needs deeper packaging and can break updates). State in description: “Start mod → my menu → Play”. Reddit modders confirm custom Main/Pause menus work as blueprints; full title-screen replacement is fragile — prefer entry-map menu.

Package & pause bonus

Package plugin with MenuMap included, test packaged (PIE lies about Open Level names!). Pause bonus: Esc Action → Create W_Pause (Resume/Restart/Menu/Quit) → Set Game Paused true + UI Only; Resume → Remove + Unpause + Game Only. Neighbor AI while paused: also Set Global Time Dilation 0? No — use Set Game Paused (dilation breaks Timeline doors).

Black screen / clicks dead / player runs behind menu?

Level name typo (copy-paste exact). Missing UI-Only + cursor. GameMode pawn still spawns runner — override with empty pawn. Widget created twice (BeginPlay double) → gate with DoOnce.
