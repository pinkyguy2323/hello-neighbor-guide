Troubleshooting bible: 17 classic fails

Cause → 1-min diagnosis → fix → prevention. Bookmark this more than any lesson. Expanded: FPS triage + pre-package checklist.

Reference17 fixesChecklist

1–6: visibility, collision, dead Blueprint, trigger, hinge, light

Invisible: Hidden in Game / closed eye / Opacity 0 / flipped normals / under terrain. Double-click name in Outliner to fly there. Never leave Scale 0 “temporarily”. Walk-through: NoCollision → Show→Collision (no red = none), BlockAll + Add Box Simplified + Save. Dead BeginPlay: actor in folder not on level / in Construction / wrong GameMode. Print “Alive!” first line: silent = not placed, talks = white-wire break downstream. Trigger dead: Generate Overlaps false / Block not Overlap / in wall / Cast filter cuts. Print without Cast first: prints = filter issue, silent = collision/size. Box ≥150 cm, OverlapAllDynamic. Hinge: center pivot = propeller — DoorPivot trick (lesson 3). Bright: stacked Directionals / Intensity 10 / Exposure 2 → 3–4 / 1.0, delete dupe. Dark after Build: no Lightmass Volume / Static unbaked / 0 — add Volume, Preview rebuild; temp Movable to confirm bake issue.

7–10: scale, pink, None/Cast, loops

Giant/tiny: Blender units + Apply Scale; 180 cm human ruler. Pink: empty slot / Explorer-moved .uasset / sRGB mix / Cyrillic path — reassign, reimport, Latin only (Normal sRGB off!). Accessed None: empty ref (deleted target, unpicked eyedropper) — IsValid before foreign Gets + defaults. Cast Failed: chair entered player Cast — handle Failed (do nothing); it's your filter working. Infinite Loop: Tick→Spawn→Overlap no DoOnce / While no exit / Dispatchers calling each other. Editor shows culprit node — DoOnce + cooldown, counter <1000 + Break, break rings via Interface.

11–12: AI, T-Pose, FPS

AI frozen: no NavMesh Bounds Volume + Build Paths / no Controller / capsule in wall. T-Pose: no AnimBP / foreign Skeleton — native Anim back, same Skeleton, Area zones (lesson 9). FPS: 50 Movable shadows + 4K + Tick spam + Complex everywhere + 505 landscape + 20 Prints. Fix in 10 min: Static + bake, 1024 tex, LOD Auto, Timer .2s over Tick, kill Prints, Stat FPS/Unit → target 60.

Pre-package checklist

☐ Map in plugin folder, Latin name, saved, light built clean. ☐ Player Start above ground, Areas + GeneralSwitch if Neighbor house. ☐ All BPs compile, no Accessed None in Play log. ☐ Debug Prints removed, single Widget, sounds present. ☐ Full run: key → door → crowbar → boards → card → drain → finale. ☐ Package → test .pak clean copy → Workshop with icon. Google as “Hello Neighbor Mod Kit” + issue + 4.20.3 (ModDB / Steam / wiki.gg) or you'll get UE5 advice that doesn't apply.
