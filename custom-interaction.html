11. Custom functions for custom items — LMB while holding = sound & more

Hold your item, click LMB → honk, flash, throw, heal: Fire mapping, held-check (HasItem + AttachedRef + IsValid), trace vs direct call, sound + cooldown + effects. Patterns from ModDB Gate/Switch + Text-trigger tutos and UE 4.20 input docs.

MediumNEWLMB = magic

📑 Contents

  1. How holding works in HN
  2. LMB mapping

How holding works in HN

HN pickup = Overlap → AttachToComponent (HandSocket) + HasItem=true + HeldRef=self (see crowbar). Drop/throw = Detach + HasItem=false. So “LMB while holding” = gate on HasItem && IsValid(HeldRef) && HeldRef == this item class. Without the class check, clicking with ANY item (or empty hands) fires your horn — classic bug. Store HeldRef as Object Reference on the player; clear it on drop.

LMB mapping (old input!)

Project Settings → Input → Action Mappings → Fire = Left Mouse Button. Event InputAction Fire (Pressed) in PlayerCharacter (pressed, NOT axis — axis spams). 4.20 only; UE5 IA_Fire tutorials don't apply. Test: Print “click” on Pressed before wiring logic.

Click logic: sound + function

1

Gate: am I holding THIS?

In item BP (or player): Fire Pressed → Get Player → HasItem? → HeldRef IsValid? → Cast HeldRef to MyItemClass? success → continue; fail → nothing (or empty-click sound). Put logic in the ITEM when one item is special; in PLAYER with Switch/Class check when many items share LMB.

2

Do it: sound + cooldown

→ Play Sound at Location (Honk Cue at item pos, not 2D — 2D ignores distance) → muzzle flash (Toggle Emissive / Spawn Emitter at socket) → Do Once + Retriggerable Delay 0.4s (anti-machine-gun) → charges-- → 0 = break (Detach + Destroy + HasItem=false). Sound Cues from kit or ModDB ALL SOUNDS PACK (drop .uassets into HelloNeighbor/Content, then migrate into your mod — Zxenook tip).

InputAction Fire → HasItem? → HeldRef valid? → Cast MyItem?
↓ yes
Play Sound at Location + flash → cooldown 0.4s → charges-- → 0 = consume

Cast HeldRef — identity check (“this exact horn, not a key”). At Location vs 2D — Location = directional/loud-nearby (Neighbor hears it! AI investigates — great gameplay); 2D = UI beep. Cooldown — 60 clicks/sec melts sound pool. Charges — int with Branch 0 → consume, like boards.

More functions (pick one, then combine)

1) Scare-horn: loud sound + Make Noise (Loudness 1.0) → Neighbor investigates (uses native AI hearing). 2) Flashlight click: Toggle Spot Visible + emissive (needs Stationary/Movable, see TV pattern with Dynamic Instance). 3) Throw: Detach + Add Impulse Forward×1500 + HasItem=false (boomerang crowbar!). 4) Heal/use: charges-- → Apply Heal / Open linked door via Interface (lesson 8). 5) Combo: LMB = sound, hold 1s (Button Down time + Timeline) = big blast. Distinguish Pressed vs Released: start charge on Pressed, fire power by hold-time on Released.

Fires empty-handed / no sound / machine-guns / AI ignores?

Add HeldRef class gate. Cue missing → test kit Cue first; Location needs attenuation. Cooldown 0.3–0.5s + DoOnce. AI: use Make Noise / loud Location cue near Neighbor + Area zones present.
