▲ Host it free so posts are shared

Static files work by double-click. Shared community needs a URL + optional free database. 5 free ways below, cheapest first.

100% free tiersNo credit card

1. Fastest: Netlify Drop / Itch.io (2 min, local posts only)

Zip hello-neighbor-guide-en → drop at app.netlify.com/drop → you get https://xxx.netlify.app. Or itch.io → New Project → HTML → upload zip + tick “mobile friendly”. Everyone sees the guide; community posts stay per-browser (localStorage) + shareable via Export/Import JSON. Zero config, perfect for school/friends.

2. GitHub Pages (free forever, recommended)

1. github.com → New repo hn-guide → Upload hello-neighbor-guide-en/* 
2. Settings → Pages → Deploy from branch → main / root
3. Open https://USERNAME.github.io/hn-guide/
# Custom domain optional. Update = drag new files.

3. Vercel / Cloudflare Pages (free, fast)

Vercel: vercel.com → Add New → upload folder → Deploy. Cloudflare: dash.cloudflare.com → Pages → Upload assets → Deploy. Both give HTTPS + preview URLs. Same as above: shared guide, local posts.

4. Shared posts for everyone: Firebase Firestore (free Spark)

1. console.firebase.google.com → New project (no billing) → Build → Firestore → Create (test mode for demo!)
2. Copy web config → paste into config.js → firebase: {apiKey, authDomain, projectId, appId}
3. Collection hn_posts auto-created on first post. Rules for demo:
   allow read: if true; allow write: if true;
   # Production: add Auth + validation! Free quota ~50k reads/day — enough for a class.
4. Redeploy static files. Community page status turns “Mode: firebase (shared)”.
⚠️
Security note

Open rules = anyone can write. Fine for friends/class demo. For public: enable Anonymous Auth + rule “request.auth != null + title.size() < 200” and add abuse report button.

5. Alternative: Supabase Postgres (free, open-source)

1. supabase.com → New project (free) → SQL → create table:
   create table hn_posts (id bigint generated always as identity primary key,
     title text, author text, cat text, tags text, body text, created bigint, likes int);
   alter table hn_posts enable row level security;
   create policy "open" on hn_posts for all using (true) with check (true);
2. Project Settings → API → copy URL + anonKey → config.js → supabase: {url, anonKey, table:"hn_posts"}
3. Redeploy. Status: “Mode: supabase (shared)”.
