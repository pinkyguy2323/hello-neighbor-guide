10. Add your objects into the original Acts — spawn with F

Make a mod that, inside the ORIGINAL Acts maps, spawns your object when you press F: Action Mapping, SpawnActor BP, transform in front of player, collision safety, packaging as plugin .pak. Honest limits included — researched from ModDB Modding Guide, Steam/Reddit modders and UE 4.20 docs.

MediumNEWF = spawn

  1. How it really works (no myths)
  2. Prep: duplicate Act map, don't edit original

How it really works (no myths)

The Mod Kit ships the full game content and mods are UE Plugins (Edit → Plugins → New Plugin, packaged via Package into .pak for Workshop — ModDB “Hello Neighbor Modding Guide”). There is no official “inject any actor into shipped Acts at runtime without touching the map” API in the kit. The reliable community-tested route (ModDB installers guide, Reddit modders) is: duplicate the original Act map into your plugin → add your spawner logic there → package. Players then play YOUR copy of the Act (e.g. Act1_MyMod) with the F-spawn working. Claiming “press F in the untouched Steam Act and my chair appears without any map change” would be false — be honest with players: your mod = modded Act map + plugin content.

⚠️
Never overwrite originals

Copy, don't move: Content Browser → right-click Act map → Duplicate/Migrate into /Mods/YourMod/Content/Maps/. Originals stay intact for updates and other mods.

Prep: duplicate Act map

1

Find the Act, copy it

Content Browser → search the Act map (names differ per kit build: Act1 / StartupMap / MainMap — use search, don't guess). Right-click → Duplicate into your plugin Maps folder → rename Act1_FSpawn (Latin, no spaces). Open YOUR copy. Add Player Start check + Lightmass Importance Volume if missing, quick Build → Preview to confirm it runs with Alt+P.

2

Your object to spawn

Any BP_AmmoBox / SM_Crate or your custom mesh: must have Simple Collision (or it falls through) and Mobility Movable if physics. Keep scale 1.0, origin at base. Test-place one copy by hand first — if the hand-placed one misbehaves, spawned ones will too.

F key: Action Mapping (UE 4.20, not UE5 Enhanced Input)

Edit → Project Settings → Engine → Input → Action Mappings → + → name SpawnObject → key F (keep Shift/Alt modifiers off). This is the OLD input system — the kit (4.20.3) has no Enhanced Input, so UE5 tutorials with IA_ don't apply. In your Character or Level Blueprint: right-click → InputAction SpawnObject event appears automatically after you add the mapping. If it doesn't appear, compile settings (close/reopen Project Settings) — classic 4.20 quirk.

Spawner Blueprint: F → object in front of player

3

Graph (put in PlayerCharacter or a BP_Spawner placed in the duplicated Act)

InputAction SpawnObject (F) → Branch [CanSpawn? cooldown false] → Get Player Location + Forward Vector × 200 cm + Z +50 → Make Transform → Spawn Actor From Class (your BP, Collision Handling = Adjust If Possible But Always Spawn) → optional Attach/Launch → Set CanSpawn cooldown via Do Once + Retriggerable Delay 0.5s. Forward spawn avoids appearing inside the player (inside-spawn = physics explosion). Always set Collision Handling override or spawns inside walls fail silently.

InputAction SpawnObject (F)
↓
Loc + Forward×200 + Z50 → Make Transform → SpawnActor (Adjust Always Spawn)
↓
DoOnce + 0.5s cooldown → sound + counter++

GetActorForwardVector × 200 — spawn point in front of eyes, not inside skull. Spawn Actor From Class — needs Class pin (your BP) + Transform; return value = spawned instance (store for limit, e.g. max 20 then Destroy oldest via Array). Do Once + Delay — anti-spam: holding F at 60 FPS without cooldown = 3600 crates. Play Sound at Location — pop confirmation.

💡
Upgrades

Cycle 3 objects per F (Array + index++), spawn costs inventory (Branch HasItem → Remove), spawn only when aiming at ground (Line Trace → Break Hit → use Hit Location).

Package & play

Edit → Plugins → your mod → Package → .pak/zip → Steam Workshop Upload (Steam running, game owned) or ModDB file. Players: subscribe/copy .pak → play YOUR Act copy from the mod menu, press F — object appears. Test packaged build, not just PIE: cooker strips unused assets, so reference your BP from the map (placed spawner) or add to Project Settings → Packaging → List of maps to include. Sources: ModDB Hello Neighbor Modding Guide (plugin/package/play), DrHello installers tuto, UE 4.20 Input + SpawnActor docs, Epic main-menu/UMG docs for flow.

F does nothing / spawns inside me / crashes / missing in package?

No event: mapping name mismatch or old input — re-add + restart editor. Inside me: +200 forward + Z50 + Adjust-Always-Spawn. Crash: null Class pin or infinite spawn on Tick (use Pressed event + cooldown). Missing packaged: hard-reference in map + packaging map list.
