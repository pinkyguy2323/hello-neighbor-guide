8. Advanced Blueprint

Direct/Cast/Interface/Dispatcher, Functions, Arrays/Struct/Enum, honest SaveGame, power grid: generator → switch → lamps → electro-door. Architecture over spaghetti.

HardArchitecturePower grid

4 ways to talk

WayWhen
Direct Ref (eyedropper var)2–3 objects forever linked (door knows its lamp)
Cast (are you player?)Check class + grab vars (door → HasKey). Simple, hard link
Interface BPI_InteractOne E for everything (door, valve, TV, switch): Trace → Does Implement? → Interact message. No 10 Casts!
Dispatcher OnPowerChanged(bool)One → many (generator → 10 lamps + door + TV). Lamps Bind on BeginPlay, generator Calls

Rule: 1 door + 1 key = Direct. “Is it player?” = Cast. Shared E = Interface. Whole-house power = Dispatcher. Casts across the map = spaghetti + cyclic deps — break with Interface/Dispatcher.

Functions, Custom Events, data

Function TryOpenDoor(Player) → Success? with Inputs/Return + locals (temp counters) — extract anything repeated 2×, verb names. Custom Event PowerOn/Off/Alarm — “do it!” with no return, called cross-BP. Array Lamps[]: ForEach → power all; Length/Add/Remove/Contains. Struct S_Key: KeyID, KeyName, KeyColor, Used → Inventory[] = backpack. Enum E_DoorState: Locked/Closed/Opening/Open/Closing + Switch-on-Enum — kills 3 contradicting bools.

E → Switch on E_DoorState
↓
Locked: check key | Closed: Opening+TL | Open: Closing | Busy: ignore

SaveGame honesty + power grid

UE 4.20 has SaveGame → Save/Load Slot for flags (keys, WaterDrained). But kit packaging + Neighbor AI memory are custom — simple flags save fine, full “Neighbor memory” may not survive .pak updates. Test packaged, not just PIE; else state “one-sitting level”. Grid: BP_Generator (HasFuel? fuel can in shed → IsRunning + loop sound + Call OnPowerChanged(true)) → BP_Switch (Powered = Running && SwitchOn) → BP_Lamp (Bind → light + emissive + click) + BP_ElectroDoor (E → Powered? else “No power!” even with key → key check from lesson 3). Native BP_GeneralSwitch if it's the Neighbor's house — AI finds it. Add 10th lamp = Bind, not generator rewrite.

E generator → HasFuel? → Call PowerChanged(true)
↓ subscribed
Switch: Running && On → Lamps on → Door Powered → E: Powered && Key = open
Dispatcher silent / cyclic dep?

Bind on lamp BeginPlay (once), Call on power change (Target wired). Door↔lamp mutual Casts → replace with Interface/Dispatcher.
