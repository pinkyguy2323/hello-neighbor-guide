6. Day, night, timers & on-screen text

5-min auto cycle (sun Timeline + color/fog), N-key toggle, event night (“picked item → dark”), Print vs UMG Widget hints “Need red key / Press E” built from scratch. Based on ModDB Tuto #5.

MediumHorror moodWidget from zero

Auto day/night

Sun + Sky to Movable or Timeline can't rotate them! Remember 4 pitches: day −55°, sunset −12°, night +25° (moonlight Intensity .15–.25 color #5A7BFF), dawn −30°. BP_DayNight Timeline 300s Loop: SunAngle keys (0=−55,120=−55,180=−12,240=+25,270=+25,300=−55). Update: Set sun rotation → Lerp color/intensity by range → Sky .3 night / Fog .03 + Post Exposure .85 night vs 1.0 day. Night lamps: Array or Tag=NightLight → night? ForEach Visible+1500 : off + emissive shade. Player feels “dark = hide”.

BeginPlay → Play TL_Day Loop
↓ Update
Angle → rotation + color/intensity → lamps on/off + fog/sky

Button & event + timers

Test key: Action ToggleNight (N) → FlipFlop → freeze Timeline + force night/day (screenshots). Gameplay: pickup after HasKey=true → Get DayNight → NightNow → Jump to 240s + “Something changed… dark” (“took key — Neighbor woke”). Countdown: Set Timer by Event 5s → close door/siren — stoppable via Clear Timer unlike Delay.

Text: Print vs Widget

Print = 2-sec debug, ugly. UMG Widget + Text Block = real game UI. 3D Widget = in-world sign (heavy, 1–2 only). Build W_Hint: Add → User Interface → Widget Blueprint, Text Block bottom-center size 24 + shadow. Player/Level BeginPlay once: Create Widget → Add to Viewport → save HintWidget. Door Overlap: HasKey? “Press E to open” : “Need red key” → Visible; EndOverlap → Hidden. Type is Text not String. #1 bug: Create in Overlap = 10 stacked widgets — create once, only SetText/Visibility later.

Door Overlap → HasKey?
↓
TRUE “Press E…” / FALSE “Need red key” → Visible → End: Hidden
Sun frozen / too dark-bright / text stuck?

Movable + Loop + Update wired. Night .2 not 0, Sky .3, Exposure 1.0 day. IsValid HintWidget + single instance.
