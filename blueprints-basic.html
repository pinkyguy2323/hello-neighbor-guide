5. Blueprint for beginners

Actor/Component/Event/Variable, wire colors, 16 core nodes with mistakes, magic-cube practice. After this you read puzzle schemas like text.

EasyFoundationCube practice

Wire colors

White = execution order (always first!). Red Boolean, light-blue Integer, green Float, pink String/Name/Text (Name for tags, Text for UI), yellow Vector, purple Rotator, orange Transform, blue Object ref (empty = Accessed None).

⚠️
White wires rule

Color pins without a white path do nothing. Route Event → action in white first, then feed data.

16 core nodes (use + mistake each)

BeginPlay — once at start (remember shark Home). Mistake: in Construction or on actor not placed. Tick — ~60/s (chase). Mistake: heavy Spawn/Print on Tick. Branch — if/else on bool. Mistake: int without Equal. Delay — N-sec pause. Mistake: on Tick (hundreds pile up). Print String — debug text (key “1” to dedupe). Remove before shipping — use Widget (lesson 6). Set/Get — write/read var (Ctrl-drag = Set). Sequence — Then 0 then 1 (not waiting!). Do Once — one shot until Reset (pickup, valve). FlipFlop — toggle A/B (one per door!). Timeline — 0→1 curve (door 0→90°, drain 1→0); mesh must be Movable, Update wired. Cast To — “are you player?” + access vars; handle Failed. Is Valid — null guard before every foreign Get (kills 90% Accessed None). Destroy/Spawn — remove key / create actor (needs Class+Transform, check Target!). SetLocation/Rotation + Play Sound — move shark/door, beep at reader; Movable + DeltaTime in Tick.

Practice: magic cube

BP_MagicCube: Cube Movable BlockAll + Box 400 Overlap, vars Home, IsAway. BeginPlay: Home = Location. Graph: BeginOverlap → Cast Player → IsValid → Branch[!IsAway] → IsAway=true → Location + up/side 300 → Delay 2.0 → Home → IsAway=false. Without IsAway it jitters — flags explained. Test: approach 5×, returns exactly to Home.
