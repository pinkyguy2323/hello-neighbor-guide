3. Puzzles: doors, keys, keycards, boards & crowbar

Timeline door, HasKey/IsLocked, 3 colored keys (ID/Enum), card reader with lamp, boards + crowbar, 6-stage quest. See water & shark for the valve finale.

MediumCore6 mechanics

Simple Timeline door

BP_DoorSimple: frame Static BlockAll + leaf Movable + Box 200 OverlapAllDynamic. Pivot on hinge (Scene DoorPivot trick). Graph: BeginOverlap → Cast Player → PlayerNear=true → E + Branch → FlipFlop → A Play TL / B Reverse → Update Lerp 0→90 → SetRelativeRotation. Keep trigger 180 cm front-side only.

Key door

BP_Key: Overlap → HasKey=true → sound → Do Once → Destroy. Door IsLocked=true: E → IsLocked? → HasKey? → true: Unlock + TL / false: “Need key”. HasKey lives on player, IsLocked on door.

Multiple keys

Int ID 1/2/3 + NeededID (simplest), Enum Red/Green/Blue (readable), Name/String tags (flexible, typo-prone), Object Ref (exact). Player: Array int Keys + Contains. Reusable (HN style) vs one-time (Remove).

Keycard reader

Reader box + red Point + emissive bulb. E: HasCard? → Powered=true → green + material swap + Beep + TL / else red blink + denied sound.

Boards + crowbar

3 boards Movable BlockAll tilted ±10°, BoardsLeft=3 locks main door. Crowbar pickup: HasCrowbar=true → Attach HandSocket. E: BoardsLeft-- → Crack → physics impulse → Delay → Destroy → 0 = Unlock.

6-stage quest

Red key → wardrobe → crowbar → 3 boards → keycard → e-door → valve finale (lesson 4). Track in GameMode + Widget hints.

Door spins / through-wall trigger / key ignored / snap?

DoorPivot trick; shrink trigger + distance check; Print HasKey + Cast class; Timeline 1.0s + Lerp + Movable leaf.
