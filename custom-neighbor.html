9. Replace the Neighbor with your model

Safe way: keep native AI, swap only the body. Skeletal/Skeleton/Rig, FBX import, same-skeleton rule, 10 child-BP steps, Area zones, 6 T-Pose diagnoses. From NeighborModKit + Wiki.

ProNo AI breakage10 steps
⚠️
Not guaranteed on every kit build

Kits moved 4.18 → 4.19.1 → 4.20.3; BP names differ. No BP_NeighborCharacter? Search Neighbor*/AI*/Enemy*. Principle (child class + same Skeleton) is identical.

Dictionary + import

Skeletal Mesh = bendable character (vs Static statue). Skeleton = bone set (thigh→shin→foot); one Skeleton → many models. Rig/Bones + skin weights. Anim Blueprint = “speed → walk/run/caught”. Retargeting = transplanting anims bone-to-bone — perfect only on identical skeletons. Blender: A/T-pose, UE bone names (root,pelvis,spine,head,upperarm_l…), 180 cm, Apply transforms. FBX 2014–18 with bones, no APEX cloth. Import: Skeletal=true, Skeleton = Neighbor's (!), Materials=false, Import Normals. Anims are baked for one Skeleton: same Skeleton = all anims fit; humanoid ≈ Humanoid Rig retarget (fingers/face may warp); quadruped = new anims needed (skip for first mod). NeighborModKit (ModDB) shortcut: pre-wired Neighbor заготовка — swap Mesh only.

10 safe steps

1) Find BP_NeighborCharacter (Components: Skeletal + Capsule + AI + AnimBP). 2) Never edit original! 3) Right-click → Create Child → BP_Neighbor_My. 4–5) Mesh slot → your model; nudge Location/Rotation inside capsule (often Z −90), Scale 1.0. 6) Skeleton check: names match root/pelvis/spine? Else switch Mesh to Neighbor Skeleton + Retarget. 7) Anim Class stays native (None = T-Pose; foreign skeleton = duplicate + Retarget Manager). 8) Own mats per slot (pink = empty). Compile+Save. 9) Place child + BP_AreaNeighborHouse + BP_AreaPlayerHouse (AI needs territory, Wiki Update 2) + BP_GeneralSwitch for electrics. 10) Playtest: patrol → notice → chase → catch.

6 diagnoses

T-Pose slide / twisted limbs / giant / sunk / sliding / wrong style?

T-Pose: no AnimBP or foreign Skeleton — restore native Anim, same Skeleton, reimport. Twisted: L↔R mapping or bone lengths — Humanoid Rig per-bone check, Scale 1.0. Giant: Blender units — re-export. Sunk: mesh offset in capsule (Z ≈ −half capsule, −90). Sliding: AnimBP gets no speed — must inherit native Neighbor, not clean Character. Style: monster walks like accountant — new anims or own it with night lighting (lesson 6).
