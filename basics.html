1. Map basics: sky, light & landscape

Empty level → 4 editor windows → sun + Sky Light + Atmosphere + Fog + Post → Static/Stationary/Movable with 6 presets → Build Lighting → Landscape hill/road/pit/platform. Expanded: exposure science + Lightmass deep-dive + fall-through matrix.

EasyRequiredResult: playable meadow

Goal

Actor — anything placeable. Component — a part of an Actor (mesh, collision, light). You will finish with MyFirstMap_EN: blue sky, sun shadows, distance haze, 63×63 m ground with hill, dirt road, pit and 12×12 m flat pad. Alt+P to run without falling.

4 windows

Viewport — 3D eye. Top bar: Perspective/Top, Lit/Unlit, fly speed. Black view = Unlit mode or camera underground — press F on a selected object. Content Browser — asset warehouse below. Never drag .uasset via Windows Explorer — use Migrate or links break. World Outliner — object list (right-top). Details — settings of selection; use its search box for Intensity instead of scrolling.

💡
Lost panel?

Window → Content Browser / World Outliner, reset via Window → Reset Layout.

New level & save

1

Empty level

File → New Level → Empty Level (not Default — Default drags extra lights you will duplicate). Black grid = normal, no light yet.

2

Save inside your plugin

File → Save Current As… → /Mods/YourMod/Content/Maps/MyFirstMap_EN. Latin only, no spaces — spaces break .pak packaging. Ctrl+S every 5 min; 4.20 crashes on weak PCs during Build.

3

Player Start

Place Actors → Basic → Player Start, lift Z +100 cm. Without it you spawn at 0,0,0 — often inside ground.

Sky rig (5 actors)

1) Directional Light (sun): Rotation Y −50°, Intensity 3–5 day, color #FFF2DF, Cast Shadows on. 2) Sky Light: SLS Captured Scene, 1.0 — fills shadows so they are not pitch black. 3) Sky Atmosphere + Exponential Height Fog Density 0.01–0.03 day. Early kits (4.18/4.19) had Atmospheric Fog instead — use it, same idea, never both (overexposure). 4) Post Process Volume with Infinite Extent=true: Exposure 1.0, Saturation 1.1.

⚠️
Version note

Final Mod Kit is 4.20.3 with Sky Atmosphere. If your Place Actors shows Atmospheric Fog, you are on an older kit build — follow the same numbers with Density 0.3–0.6.

Lights & Mobility + 6 presets

LightUse
DirectionalSun/moon, 1 per outdoors
PointBulb, Attenuation 400–800
SpotPorch/cone 40–60°
SkyFill, always 1

Static — baked, fastest. Stationary — fixed position but color/brightness changeable (lamp that turns off). Movable — dynamic every frame (flashlight, rotating sun). Key params: Intensity, Color, Attenuation Radius, Source Radius (soft shadow), Cast Shadows.

Presets: Day 4.0 #FFF3E0 Y−55° / Sunset 2.2 #FF7A2F Y−14° Fog .045 / Night 0.2 #6A86FF Sky .3 / Room Point 1200 r700 #FFE7C2 Stationary / Desk lamp 600 r350 / Window Spot 3000 cone 45° cold.

Build Lighting

Static/Stationary must be baked: add Lightmass Importance Volume around play area, Build → Lighting Quality → Preview (draft) / Production (final) → Build Lighting Only. Movable needs no bake but costs FPS. Deep-dive: Lightmass shoots photons from lights, bounces via Irradiance Cache; without Volume it samples infinity → dark map. Keep UV Lightmap 64+ on walls or bake shows blobs.

Landscape practice

Modes → Landscape → Create New 63×63 (fast). Tools: Sculpt (Shift=invert), Smooth after every hill, Flatten click-height then paint pad, Noise 0.05, Erosion if present. Paint needs Layer Blend material + per-layer Layer Info or brush paints nothing (#1 complaint). Hill: size 1200 str .4 ×3 → Smooth. Road: Flatten narrow + brown layer. Pit: Shift+Sculpt. Pad: Flatten 1200×1200 cm square.

Too bright / dark after build / black sky?

Bright: two Directionals stacked or Exposure 2. Dark: no Volume or Static unbaked. Black sky: missing Sky Light or Lit→Unlit. See troubleshooting.
