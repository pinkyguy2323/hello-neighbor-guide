7. Custom 3D models & BP props

Blender → FBX 2014–18 → 6 texture maps → emissive screen material → Simple/Complex/UCX collision → BP_TV on/off with sound + light. Plus lamp-trap variant + pink-material flowchart.

HardBlender → UE 4.20TV practice
⚠️
Formats for 4.20.3

Models FBX binary 2014–2018 triangulated (no glTF/USD). Textures TGA/PNG 1024–2048, Normal = DirectX (not OpenGL). Latin names only: SM_TV_Body, T_TV_Screen_BC.

Prep: scale, Pivot, UV

1 unit = 1 cm. TV 60×40×40. Apply Scale (Ctrl+A), origin to bottom so it sits on tables. UV 0–1 clean (Lightmap UV auto-generated, but base UV must be clean or bake blobs). 2 Blender materials: M_Body + M_Screen as separate mesh/polys or you can't toggle emissive.

Export & import

Blender FBX: Scale 1.0, Apply Unit, -Z/ Y up, Selected only. UE Import to Content/Meshes: Materials=false, Textures=false (separate!), Auto Collision=true, Lightmap UVs=true. Auto-mats = pink slots — build your own. Textures to Content/Textures: BaseColor sRGB on, Normal = Normalmap sRGB off!, Rough/Metal = Masks sRGB off! (wrong sRGB on Normal = pimples).

6 maps + screen material

BaseColor (albedo), Normal (bumps, purple — normal), Roughness (white matte / black gloss: body .6, screen .15), Metallic (plastic 0, chrome 1), Emissive (self-glow), Opacity (glass .3, TV unused). M_TV_Screen: texture → BaseColor, Scalar ScreenOn 1.0 × Emissive → Emissive, Roughness .15. Blueprint drives ScreenOn 1↔0 — no material swap. M_TV_Body: color + Rough .6.

Collision: why you walk through

Simple box (fast — TV/walls): mesh → Collision → Add Box Simplified → Save, BlockAll. Complex per-triangle (slow — statues): Complexity → Use Complex as Simple. Custom UCX_ box from Blender for exact holes. Diagnose: Show → Collision (no red = NoCollision). Pink? Empty slot / moved .uasset via Explorer / sRGB mix / Cyrillic path — reassign, reimport, Latin only.

BP_TV + lamp variant

Components: Body Static BlockAll + Screen Static NoCollision + Point 800/r400 off + Audio hiss + Box trigger. Vars IsOn, MID_Screen. BeginPlay: Create Dynamic Instance (M_TV_Screen) → set on screen → save → ScreenOn 0. E FlipFlop: A on (ScreenOn 1 + light + sound + “TV on”), B off. Dynamic per-TV or all TVs toggle together! Variant: same BP as lamp-trap (Spot + hum) gated by generator power from lesson 8: no power → “No electricity”. Upgrades: 3 channels cycle, static noise, auto-off on EndOverlap for FPS.

BeginPlay → Dynamic Material → set on screen
↓
E FlipFlop → A: 1.0 + light + sound | B: 0.0 + off
Giant/tiny, pink, ghost, all TVs sync?

Re-export Scale 1.0 (temp Details scale lies physics). Reassign mats + Latin paths. Add Simplified + BlockAll. Use Dynamic Instance per TV.
